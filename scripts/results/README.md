# 发布与验收结果的保留约定

每次正式发布保留一份回执，记录发布号、源码版本、镜像摘要、晋级指针和结果。已结业务问题保留最终验收结论、复现条件和关键证据。专项仍在跟踪时，保留继续定位所需的原始记录。

批次结案后，可清理已有汇总覆盖的预检、重复状态快照、构建过程输出和已过时的容量盘点。清理前检查 CI、脚本和文档的引用，保留实际消费的文件，并把历史附件链接固定到清理前的提交。测试夹具、回滚必需物料和验收基准按各自用途维护。

2026-11-29 清理了部分 9 月 KIND runner 联调、Harbor 和缓存空间盘点、10 月 Jenkins 建设批次的过程附件。历史回执中以短文件名记录的附件，可以在[清理前的目录](https://github.com/sunmoonlion/sunmoonun/tree/c93a1af7ff40c2dabc2408e44a2c6782372786b4/scripts/results)中按原名查阅。
