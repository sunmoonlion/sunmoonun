2026-11-03，Luna；第二轨后续开发，未部署，不移动Qwen当前测试修复候选。

运行器的 `placed()` 将作者声明的成稿路径放到本次任务目录，只保留文件名。
原动态计划校验按声明路径比较，允许 `analysis/report.md` 与 `forecast/report.md`
同时出现，实际均落到同一个 `report.md`；也允许成稿占用系统另写的 `交回.md`。

同时核对实际目标文件名，不区分大小写。保留原声明路径检查，只检查选中的方法；
可选且未选的方法不影响本次计划。规划提示说明限制，不授权模型更改冻结文件名。
