# 财务分析与预测：规范能力声明核对稿

以下为准专家4.11实际声明内容。测试和发布记录独立保存，不属于能力声明。

单家公司财报指标计算、披露核对与固定方法季度预测。

## F1 历史财报指标与走势

| 栏目 | 声明 |
| --- | --- |
| 目标与结果 | 计算并描述营业收入、归母净利润、营业成本及核心财务指标的历史走势。 |
| 适用范围 | 一家中国A股上市公司；明确历史期间及合并或母公司口径。 |
| 方法与边界 | 毛利率=(营收−营业成本)/营收；净利率=归母净利润/营收；ROE按平均归母净资产；经营现金流/归母净利润；同比；明确要求时计算CAGR。 |
| 数据前提 | 授权报表与可核页码原文；同比需比较期，平均净资产需期初期末，CAGR需起止数和年数；重述版本分开。 |
| 交付 | 年度金额、指标、走势、计算依据、口径及出处，纳入Markdown报告。 |
| 不适用与不承诺 | 不承诺因果识别、经营诊断、审计鉴证、横向选股；人均创收等非标准指标须先确认作者方法与人数口径，不自动视为覆盖。 |
| 条件不足 | 主体、期间或口径不清先澄清；缺数走数据确认；分母不成立标不适用；原题要求缺失不能报完成。 |
| 适用例 | 计算某A股公司2021至2024年的营收、归母净利润、毛利率与三年营收CAGR。 |
| 不适用例 | 证明利润下降的唯一原因并提出经营改造方案。 |

## F2 累计报表转单季

| 栏目 | 声明 |
| --- | --- |
| 目标与结果 | 将利润表、现金流量表的累计金额还原为单季序列。 |
| 适用范围 | 一家中国A股上市公司的可比季度序列，作为本专家分析或预测的输入。 |
| 方法与边界 | Q1=一季报；Q2=半年报−Q1；Q3=三季报−半年报；Q4=年报−三季报；资产负债表时点数不差分。 |
| 数据前提 | 同口径、同版本链的累计报表及相邻累计期；使用前核对原四条恒等式，差额超过1元为不平，缺项不冒充通过。 |
| 交付 | 单季序列、差分计算依据、来源与不可用期间，纳入Markdown报告。 |
| 不适用与不承诺 | 不把年度数平均分摊为季度，不推造缺失季度，不将重述前后数据直接混算。 |
| 条件不足 | 缺相邻累计期先提数据需求；仍缺则明确不可还原，不用估算填充实际值。 |
| 适用例 | 用半年报和一季报还原第二季度营业收入。 |
| 不适用例 | 只有年报，拆出四个季度的真实收入。 |

## F3 分析结论与管理层讨论对照

| 栏目 | 声明 |
| --- | --- |
| 目标与结果 | 逐条判断本专家上游分析结论是否得到管理层讨论原文支持。 |
| 适用范围 | 依赖本次上游结论及对应年报；只读按目录定位的管理层讨论章节。 |
| 方法与边界 | 保留每条结论原文；完整同口径支持才判支持；未提及、仅部分支持或口径不同判不支持并说明。 |
| 数据前提 | 可读且有页码的年报原文、章节定位和本次上游结论。 |
| 交付 | 逐条结论、支持/不支持、原因及支持项原文引文和页码，纳入Markdown报告。 |
| 不适用与不承诺 | 不支持不等于计算错误；不以其他章节代替管理层讨论，不据此保证结论因果正确或无舞弊。 |
| 条件不足 | 找不到章节或无上游结论如实说明，不能编引文或把缺少材料判为已核对。 |
| 适用例 | 将本次营收同比结论对照年报管理层讨论，并引用支持它的原文。 |
| 不适用例 | 根据管理层讨论证明公司不存在财务造假。 |

## F4 固定方法的两季度预测

| 栏目 | 声明 |
| --- | --- |
| 目标与结果 | 测算营业收入、归母净利润未来两个季度的点预测和区间。 |
| 适用范围 | 一家中国A股上市公司；明确预测起点、两个目标季度及可比金额口径。 |
| 方法与边界 | 上年同季×(1+近4季同比中位数)；上下界用近8季同比最小/最大值；先回测最近4个单季。 |
| 数据前提 | 单季还原、同比和各回测时点所需历史窗口；预测使用期通过原四式核验，差额阈值1元，缺项或不平期不冒充合格；披露时点与重述差异另列。 |
| 交付 | 两季度点值及上下界、最近4季回测、计算依据、出处与局限，纳入Markdown报告。 |
| 不适用与不承诺 | 不做DCF、股价/目标价、五年预测、三表联动或用户指定的其他模型；区间不是统计置信区间，不保证实际值落入。 |
| 条件不足 | 起点不明确先澄清；缺数据先确认补取；窗口或核验仍不足则说明无法完成，不缩短回测要求冒充交付。 |
| 适用例 | 按季节性同比法预测未来两季度营收和归母净利润，并回测最近4季。 |
| 不适用例 | 用DCF给出合理股价，或预测未来五年的三张报表。 |

## 实际入包内容

当前scope/v1仍为三个文本字段；下面由同一份能力卡生成，保留共同约束。不是新结构化契约已上线的声明。

### does

共同前提：资料经本次授权；可查询/补取不代表已具备，也不保证能取到。按已有八步流程执行，不承诺任意方法组合或即时完成。报表先按原四条恒等式核对：资产=负债+权益；归母净利润+少数股东损益=净利润；期末现金=期初现金+净增加额；本期期初=上期期末。年度衔接比余额，重述差异另列。最终交付财务分析报告.md。
