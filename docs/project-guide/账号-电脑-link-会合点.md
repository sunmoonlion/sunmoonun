# 账号、电脑、link、沙箱、令牌、会合点

界面、文档、卡片说到这几样时，只用本页的叫法。本页 2026-10-23 按所有者定的「三个过程」重写。

## 一、六样东西

| 东西 | 是什么 | 在哪 | 我们能知道它什么 |
| --- | --- | --- | --- |
| **账号** | 一个身份 | 云端 | 全部 |
| **电脑** | 一台实体机器 | 用户手里 | 只能听本地 link 报 |
| **本地 link** | 装在电脑上的程序（程序名 sunmoon-link） | 用户的电脑上 | 它报的电脑名（默认取操作系统主机名，可改）、系统、设备编号、连没连着会合点 |
| **沙箱** | 云端替这个账号跑 Codex 的容器；每个账号一个，拉起后常驻 | 云端 | 全部 |
| **令牌** | 后端给账号签的凭证，写明配给哪个账号、编号、到期时间。每个账号一对：本地 link 一份（30 天到期），沙箱一份（90 天到期）；再颁发时两份一起换 | 本地 link 那份存在它的配置目录里；沙箱那份后端加密保存 | 签给谁、什么时候到期、吊销了没有 |
| **会合点**（relay） | 本地 link 和沙箱往外连的中转服务器：核验令牌，把同一账号的两端接上，逐条转发 | 云端 | 此刻每个账号的本地 link 连没连着；沙箱只在干活时才连上来 |

## 二、三个过程

按先后：**安装 → 颁发令牌 → 配对**。

| 过程 | 谁做 | 做什么 | 结果 |
| --- | --- | --- | --- |
| **安装** | 用户 | 在设置「电脑与沙箱」下载安装包，装到电脑上。装完本地 link 第一次运行：生成设备编号，自动打开确认页，接着进入颁发令牌 | 本地 link 装在这台电脑上 |
| **颁发令牌** | 后端签，用户确认 | 后端给账号签一对令牌。沙箱那份后端直接交给沙箱。本地 link 那份要用户点「允许」才交出：确认页显示确认码和要配给的账号，用户核对后点「允许」，本地 link 拿到令牌存下 | 本地 link 配给这个账号 |
| **配对** | 本地 link、沙箱 | 本地 link 拿令牌连会合点，一直连着；沙箱在运行、拿着有效令牌，Codex 要动用户电脑时随时连上来。会合点核验两边的令牌（签名对、没过期、没吊销），把同一账号的两端接上 | 本地 link 连着、沙箱就绪：配对成功 |

- **首次颁发**：安装后本地 link 自动打开确认页，用户不用去托盘找入口；「允许」这一下不能省——后端不知道一份本地 link 归谁，要用户在登录了账号的浏览器里点允许来证明，不然谁装一份本地 link 都能领走别人的令牌。沙箱是后端自己拉起的，它那份不用确认。
- **再次颁发**：本地 link 的令牌失效（到期或被吊销）时，用户点「重新颁发令牌」（托盘或设置），再走一次确认页。后端签新的一对，旧的一对按编号吊销：拿着旧令牌的本地 link 被断开、再连被拒；沙箱在运行时换上新令牌。
- **颁发和配对是两回事**：颁发是发凭证，配对是拿凭证连会合点。令牌有效、只是网断了或本地 link 没在运行，是配不上对，重新颁发也没用。
- **沙箱看「就绪」，不看「连着」**（2026-10-23 核代码更正）：沙箱一侧的出站桥只在 Codex 要动用户电脑时才连会合点，用完就断，平时不挂着；所以沙箱这一端说的是**就绪**——在运行、拿着有效令牌、能马上接活。本地 link 才是一直连着的那一端。
- **沙箱什么时候拉起**：在设置「电脑与沙箱」里拉起，要先在「模型」里登记模型 key；登录网页不会自动拉起。拉起后常驻，不会因为闲着停掉，所以沙箱没就绪就是不正常。

## 三、关系

| 关系 | 谁和谁 | 怎么建立 | 一对几 |
| --- | --- | --- | --- |
| **装在** | 本地 link 装在电脑上 | 安装 | 一台电脑装一份本地 link |
| **登录** | 浏览器用账号登录 | 在浏览器里登录 | 和别的关系无关：浏览器登的是 A，这台电脑的本地 link 可以配给 B |
| **配给** | 本地 link 配给某个账号 | 颁发令牌：本地 link 手里有这个账号的有效令牌 | 一份本地 link 同时只配给一个账号；一个账号同时只配给一份本地 link（再颁发一次，旧的作废） |
| **连着** | 本地 link 连着会合点 | 拿令牌往外连，自动保持、断了自动重连 | 实时：电脑关、没登录系统、本地 link 没在运行、断网、令牌过期或被吊销就没连着 |
| **就绪** | 沙箱 | 拉起后常驻，拿着有效令牌 | 实时：没拉起、令牌失效、出故障就没就绪 |
| **配对成功** | 同一账号的本地 link 和沙箱 | 本地 link 连着、沙箱就绪 | 实时；缺一端就是未配对 |

- **配给这个账号的本地 link** = 最后一次给它颁发这个账号令牌的那份本地 link。配给关系一直在，直到下次重新颁发令牌。
- 账号不连谁。不说「账号连着的 link」「连接账号」，说「配给这个账号的本地 link」和「它连没连着会合点」。
- **认本地 link 用设备编号**，不用电脑名；电脑名会重名，只给人看。设备编号用在两处：
  1. **打开工作台时的核对**（第五节）：比两个编号——**甲**：眼前这台电脑上的本地 link 的编号，网页在这台电脑的浏览器里直接问本机的本地 link 拿到；**乙**：配给当前登录账号的那份本地 link 的编号，它连会合点时报过、后端记着，网页问后端拿到。
  2. **设置里一份本地 link 一条记录**：同名的两台电脑不会并成一条；重新颁发令牌还是原来那条。
- **设备编号**：本地 link 第一次运行时随机生成一次，存进它在这台电脑上的配置目录，以后一直沿用（重新颁发令牌不变）。编号本身是随机数，不含电脑或 link 的信息；它代表「这台电脑上的这一份本地 link」，靠的是存放的位置。重装（配置目录删了）就是新编号；配置目录被整个拷到别的电脑会跟过去，所以本地 link 报编号时一并报主机名与系统，对不上就提示。不读硬件指纹。它和颁发令牌时那个一次性密钥是两回事——那个每次颁发都重新随机生成、用完不存。
- 本页的「令牌」只指上面这一对（本地 link 的、沙箱的）。网页敲本地 link 用的票、工作台连会合点的服务流令牌等是别的，不在本页。

## 四、界面上的词

| 词 | 意思 | 用在 |
| --- | --- | --- |
| 连着 / 没连着 | 本地 link 此刻连没连着会合点。说的是本地 link，不是电脑：电脑开着、本地 link 没在运行，也是「没连着」 | 设置「电脑与沙箱」、管理端 |
| 就绪 / 没就绪 | 沙箱此刻在不在运行、能不能马上接活 | 设置「电脑与沙箱」、管理端 |
| 配对成功 / 未配对 | 本地 link 连着、沙箱就绪；未配对时写明缺哪一端（「本地 link 没连着」「沙箱没就绪」） | 设置「电脑与沙箱」、管理端 |
| 最近一次联系 | 最后一次看到它连着会合点的时间 | 设置「电脑与沙箱」、管理端 |
| 令牌到期日 | 本地 link 那份令牌哪天到期 | 设置「电脑与沙箱」、管理端 |
| 重新颁发令牌 | 再走一次颁发令牌 | 托盘、设置、工作台提示 |
| 确认码 | 颁发令牌时确认页上显示的码，核对是不是这台电脑发起的 | 确认页、托盘、测试电脑日志 |
| 工作台现在用的电脑 | 配给当前账号的那份本地 link 装在的电脑 | 工作台提示 |

- 不用：「在线、离线」（说不清是哪一端）、「电脑在线、离线」、「连接账号」「重新连接账号」「连到账号」、「重新配对」（指颁发令牌时）、「配对码」（改叫确认码）、「本地程序」「本地代理」，以及单说的「代理」（指本地 link 的一律改叫本地 link；「检查网络或代理设置」里的代理是上网用的网络代理，不在此列）。
- 「会合点」只用在文档和管理端。web端不出现这个词：用户只看到本地 link 连没连着、沙箱就绪没有、配对成功没有。
- 以前文档里说的「配对」（配对码、配对确认页、「配对防配错」等）指的是现在的**颁发令牌**；旧决定与旧回执的原文不改，读时按这一条对照。

## 五、打开工作台时的核对

核对两件事：**浏览器所在这台电脑上的本地 link，是不是配给当前登录账号的那份**（比编号甲和乙，见第三节），以及**配对成功没有**。结果在工作台顶上单独提示，只在要用户做事时出现；侧栏不挂这类状态。

| 结果 | 提示 |
| --- | --- |
| 甲 = 乙，配对成功 | 不提示 |
| 甲 = 乙，本地 link 被会合点拒绝：令牌到期或被吊销 | 「令牌已失效」＋「重新颁发令牌」 |
| 甲 = 乙，本地 link 在运行但连不上会合点：网断了或卡住 | 「本地 link 连不上：检查网络，或退出 link 再重新打开」（不叫重新颁发） |
| 甲 ≠ 乙（这台的本地 link 配给了别的账号，或从没颁发过令牌） | 「工作台现在用的不是这台电脑」＋「重新颁发令牌」 |
| 甲拿不到（没装、没在运行、手机、浏览器不允许检测） | 一行小字「这台设备没有在运行的本地 link，或浏览器不允许检测；工作台现在用的是『电脑名』」，不强迫 |
| 沙箱没就绪（不管甲、乙怎样） | 没登记模型 key：「先到『模型』登记 key」；登记了：「沙箱没就绪」＋去「电脑与沙箱」 |

## 九、常见情形

| 情形 | 配给 | 连着 | 配对 |
| --- | --- | --- | --- |
| 在电脑 P 上给账号 A 颁发令牌 | P 上的本地 link → A；A 之前配给的作废 | P 开着就连着 | A 的沙箱就绪就配对成功 |
| 电脑 P 关机，或没登录系统 | 不变 | P 的本地 link 没连着 | 未配对（本地 link 没连着） |
| 在电脑 Q 上又给 A 颁发令牌 | Q 上的 → A；P 上的作废 | Q 连着；P 被断开，再连被拒 | Q 与 A 的沙箱配对成功 |
| 在电脑 P 上给账号 B 颁发令牌 | P 上的 → B，不再配给 A | 替 B 连着 | A 未配对；A 在 P 上打开工作台时提示「工作台现在用的不是这台电脑」 |
| A 的本地 link 令牌到期 | 不变 | P 的本地 link 被拒，没连着 | 未配对；提示「令牌已失效」＋「重新颁发令牌」 |
| A 还没登记模型 key | 不受影响 | 本地 link 可以连着；沙箱没拉起 | 未配对（沙箱没就绪）；提示先登记 key |
| 用手机打开工作台 | 不变 | 不变 | 不变；提示这台设备没有在运行的本地 link |

## 十、托盘与保持运行

托盘是本地 link 在电脑上的界面。对用户来说托盘和本地 link 是一个东西：托盘在，本地 link 就在运行；退出就一起退出。托盘悬停时显示「SunMoon link：状态」。

| 菜单项 | 做什么 |
| --- | --- |
| 状态（灰字） | 「本地 link 连着」，或「本地 link 没连着：原因」。托盘只看得到本地 link 这一端；沙箱那一端和配对成功没有，在网页设置「电脑与沙箱」里看 |
| 查看状态与原因 | 打开详细的状态与原因 |
| 这台电脑上的设置 | 电脑名、白名单目录、上限、本地知识库目录、「登录时自动运行」勾选框；保存后本地 link 自己重启生效，不要用户手动重启 |
| 重新颁发令牌 | 再走一次颁发令牌（第二节） |
| 退出 link | 本地 link 和托盘一起退出；下次登录系统，或从开始菜单打开时再运行 |

- **不设「暂停 / 继续运行」、「启动 / 停止」**：不让云端碰这台电脑，靠白名单与上限（放宽要在这台电脑上点允许），真想断开就退出 link；退出后从开始菜单打开就是重启。
- **登录时自动运行**：颁发令牌完成时自动打开（Windows 任务计划程序里当前用户的登录任务，后台运行，失败每分钟重启、最多 3 次）。在托盘「这台电脑上的设置」或网页设置「电脑与沙箱」里勾选，两边改的是同一个开关。开机后停在登录界面时不运行。
- **会合点断开不回应的**：会合点每 20 秒 ping 一次本地 link，不回就断开，「连着」以会合点看到的为准。本地 link 自己卡住时，退出 link 再从开始菜单打开；卡住本身当缺陷修（如待办账 136）。
