## 一、市面做法（2026-10-27 查）

| 来源 | 分法 |
| --- | --- |
| Wind（所有者转述与终端截图） | 顶层按发布者分：公告、研报、财经资讯（财经资讯、推荐资讯、负面资讯）、简报（平台）等；研报平台「类别」15 个，行业、盈利预测、来源、研究员、页数、语言、深度、更新频率等另作筛选 |
| 巨潮资讯 | 公告一层 26 类（年报、半年报、一季报、三季报、业绩预告、权益分派、董事会……），分类代码见本地 AKShare 源码 `stock_feature/stock_disclosure_cninfo.py` |
| 东方财富、天软 | 公告两层（东财一级 7 类；天软约 50 项） |
| 上交所《上市公司自律监管指南第1号——公告格式》（2026-04 修订） | 按事项 56 号，是监管口径 |
| 都柏林核心（Dublin Core）元数据 | 15 个元素，发布者（Publisher）、类型（Type）、主题（Subject）、时空范围（Coverage）、日期、格式、语言等各是一个元素 |

成熟做法是**分面**：每个维度只答一个问题，各维度并列、一份资料在每个维度上各取各的值。巨潮、东财那些「业绩预告、权益分派、重组」讲的是事项，不是文献类型。

## 二、维度

三个词（所有者 10-27 问清）：**维度**是描述一份资料要填的一栏；**词表**规定每一栏能填哪些值（封闭的维度有取值清单，开放的只核格式），带版本号；**描述**是一份资料实际填出来的值。

**描述 = 进键维度 + 筛选维度**，另带两项记账信息（不是维度）：确认状态（自动识别未确认、本人确认过、入库质检过，后两种参与解析）、词表版本。

| 维度 | 只答一个问题 | 每份几个 | 进不进「认这一份」的键 |
| --- | --- | --- | --- |
| **类型** | 是什么文献（大类 = 发布者，细类 = 文献类型） | 一个细类，大类由词表推出 | **进** |
| **主体** | 讲谁 | 至多一个（证券代码、机构编号） | **进** |
| **期间** | 什么时候的 | 定期报告是报告期（年初到报告期末），其余是披露时间 | **进** |
| **版本形态** | 全文、摘要还是英文版 | 一个，缺省全文 | 定期报告进 |
| 事项 | 讲什么事 | 可多选 | 不进 |
| 行业 | 哪个行业 | 可空 | 不进 |
| 语言 | — | 可空 | 不进 |
| 格式 | PDF、Excel、CSV、文本、Markdown、网页 | 一个 | 不进（声明里照旧能限定） |
| 研报的几维 | 来源机构、研究员、评级、盈利预测、市场、深度、更新频率 | 可空 | 不进 |

- 进键的几个决定：按描述查「这一份在不在」、能不能采、去哪采、期间怎么算、怎么加工（如年报抽三大表）。改它们的取值代价最大，所以只放这几个。
- 封闭的维度（取值清单在词表里）：类型、事项、行业、版本形态、语言、格式、盈利预测、市场、深度、更新频率；开放的（只核格式或照原文记）：主体、期间、来源机构、研究员、评级。
- 其余维度只用来筛选与搜索：可空、可多选，以后加取值、补填都便宜，漏填不出错。
- 专家声明：类型可以写细类，也可以只写大类（这个发布者的都行）；事项、行业等写了就是缩小范围。
- **期间规则**：定期报告照旧（固定期间、最近 N 个完整报告期）；其余类型加 `recent`：最近 `months` 个月内披露的（1–60），截至任务日期。描述里非定期报告的期间是披露时间窗（含两端），资料按披露日落在窗里算对得上。
- **词表改版的规矩**：只加细类、加筛选维度的取值不升 `VOCAB_VERSION`，旧描述照常参与解析；改名、删除、改词义才升。契约 `knowbot-data-needs/v2` 尚未上线，本次在 v2 内直接改，上线以后同样的改动要开 v3。

讲什么事，可多选。上市公司公告的事项由 knowfeed 按巨潮分类与标题认（第四节），认不出就空着；研报、资讯、上传的资料由识别或本人填。

## 四、knowfeed 怎么认

巨潮的 26 类大多落在「临时公告」这一个细类上，差别记在事项：

| 巨潮分类 | 细类 | 事项 |
| --- | --- | --- |
| 年报、半年报、一季报、三季报 | 对应的定期报告 | — |
| 首发 | 标题含「招股说明书」「招股意向书」→ 招股书；「上市公告书」→ 上市公告书；其余临时公告 | 发行上市 |
| 业绩预告 | 临时公告 | 业绩 |
| 权益分派 | 临时公告 | 分红 |
| 董事会、监事会、股东大会 | 临时公告 | 会议 |
| 日常经营 | 临时公告 | 经营与交易 |
| 公司治理 | 标题含「投资者关系活动记录」→ 投资者关系活动记录；其余临时公告 | 治理（「业绩说明会」→ 业绩） |
| 中介报告 | 临时公告 | 中介意见 |
| 增发、配股、公司债、可转债、其他融资 | 临时公告 | 再融资 |
| 股权激励、解禁、股权变动 | 临时公告 | 股本与股东（「要约收购」→ 重组与收购） |
| 补充更正、澄清致歉、风险提示、特别处理和退市、退市整理期 | 临时公告 | 交易提示与风险 |

- 不论巨潮分类，标题含「问询函」「关注函」「监管工作函」「警示函」「监管措施」「纪律处分」的：交易所、监管机构发的原函 → 监管函件；公司的回复 → 临时公告，事项记监管。含「重大资产重组」「吸收合并」「破产重整」的事项加重组与收购。
- 版本形态照标题认：「摘要」→ 摘要，「英文」「English」→ 英文版，其余全文；已取消的、H 股的不要（照现有规则）。
- 规则带版本；改规则不回头改已交付的描述（描述改动另走留痕）。
- 按描述采时（需求单）：定期报告一份描述对一份报告；临时公告等是一个披露时间窗，可带事项，窗里对得上的全部交付（每份一份资料）。
