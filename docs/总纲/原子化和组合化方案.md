## 一、审查结论与建议

**可以把这批内容改造成供作者选用的原子方法和组合模板，但不能把现有 20 项直接改名后入库。**它们目前是混合粒度的合成候选：有独立计算、有几个分析职责捆在一起的方案、有完整模型、有报告模板，也有正文、输入和验收互相不一致的内容。

我的建议是：先修正业务定义与数据依赖，再按独立研究职责拆分；保留有价值的组合为可编辑的创意模板。方法库积累经过作者确认和实际使用验证的做法，不把“存在于代码”“有出处名称”“测试全绿”当作成熟方法认证。

具体采用四个原则：

1. **原子化服务于复用和选择。**一个原子方法有完整的研究含义、适用条件、输入、规则、结果和验收。它可以有多个公式；不是每个加减乘除都成为一个方法。
2. **组合服务于作者形成创意。**作者可以选择原子方法，使用现成组合模板，再由自己或 AI 加工定型。组合模板不自动成为专家，也不要求作者只能使用库内方法。
3. **流程、必做规则与方法分开。**“必须先检查”是专家规则；“怎样检查”仍是方法。授权、等待、审批、预算和写文件是运行机制，不因原子化而变成财务方法。
4. **原子方法数量不等于模型调用数量。**独立计算按相容的数据范围批量执行，保留逐项结果与收据。不能把目前很慢的八步，改造成几十轮更慢的模型推理。

实施上，先用现有财务专家的能力做第一份可用组合：年度分析、人均创收、单季还原、原季节性预测与回测、管理层讨论核对。DCF、三表情景预测、治理与竞争分析随后进入其他模板，不自动扩张这位专家的能力声明。

## 三、怎样认定一个原子方法

一个候选同时满足以下条件，才进入独立方法定义：

- 有一个可独立询问的问题，例如“这一期间的利润归属是否勾稽”，而非“执行第3步”。
- 换一个专家仍能使用，不依赖某个上游步骤的名称或整个专家工作流。
- 输入足以完成方法：必需事实、参数、证据及适用范围说得清。
- 输出有可直接使用的业务含义，并能单独验证。
- 缺项、零分母、口径冲突、未核验、不适用有明确处理。
- 再拆分若只剩通用算术或失去独立用途，就停止拆分。

例如 CAGR 作为一个方法，以指标、起止期间为参数，不拆成相除、乘方、减一三个方法。杜邦分解可以引用独立比率结果，但五因素的共同口径和乘积闭合本身仍有完整方法含义；不能让五个任意比率拼在一起就叫杜邦。

同一计算引擎可支持多个明确的指标配置，但每个配置必须冻结分子、分母、时点／期间、缺项、公式和适用域。作者选“人均创收”或“毛利率”，不是选一个允许模型任意填公式的“除法方法”。实现可复用，业务定义不能丢失。

## 四、20 项逐项审查与处置

以下 A/Q/O/V/R/E/P 编号是本文的建议目录编号，定义在第五节；不是现有数据库 ID。C 编号是第六节的组合模板。涉及新公式、适用边界或必做条件的内容，都须形成作者可核对的差异后定型。

### M01 财务三表标准化重构

**现有内容：**三表科目映射、重分类、单位处理及调整轨迹。交回标准三表和 `reclassification_audit_trail`。

**问题：**混合数据工程与会计解释。单位归一可由数据层完成；科目语义映射、重分类理由需要作者方法。已有源地址检查有价值，但不足以证明合并／母公司、时点／期间和重述版本相容。无重分类也要求至少一条轨迹不合理。

**处置：**保留 A01“科目及口径对齐”为业务方法；下载、解析、页码定位、单位换算沿用数据工具。调整保留原值、转换值、依据和影响，不覆盖披露事实。无调整交回空变更列表及已检查范围。形成 C01 的准备部分，不强制所有已标准化事实再跑一次。

**新增验证：**无需调整；万元到元；同名不同合并范围；重述比较期；缺少精度说明。单位换算不能虚构披露精度。

### M02 勾稽平衡与重述校验

**现有内容：**期初／期末资产负债平衡、未分配利润滚动、现金衔接、期初与上期期末比较，附调整说明。

**问题：**这不是现有财务专家原四式的等价实现：它包含未分配利润桥，却不能替代原来的“净利润=归母净利润+少数股东损益”。“不一致即识别为追溯重述”也过强，差异还可能来自范围、单位、抽取或匹配错误。标量差额不足以逐期处置。

**处置：**拆为 Q01 资产负债平衡、Q02 利润归属、Q03 现金滚动、Q04 期初期末连续性、Q05 未分配利润滚动、Q06 重述差异核对。Q02 从现有专家要求补入，不冒称候选已有。四式组合 C01 包含 Q01—Q04；Q05 按题选，Q06 有差异且有披露依据时使用。

Q04 只能比较同科目、同范围、同余额日的存量，不能把累计收入或现金流当期初余额。保留差额方向。作者原政策“超过1元不平”对应 `abs(diff) > 1`；先统一正文和实现的边界，不悄悄改成 `<1`。粗精度原文不足以确认1元级一致时标未核验，是否采用舍入容差须单独确定。

**新增验证：**恰好1元／超过1元；原四式逐项；利润归属漏项；真实不平被正确交回；流量冒充余额；重述有／无证据；两边各自平衡但口径不一致。

### M03 扣非损益与单季还原

**现有内容：**剔除非经常性损益、核心利润率、累计转单季。输入却主要是勾稽结果摘要。

**问题：**三个可独立选择的职责绑在一起。扣非需要明确税后、归属母公司口径及披露分类，不能机械扣掉所有政府补助或公允价值变动。季度表目前偏重 sourced，不能替代差分计算及其两份来源链验证。

**处置：**A02 扣非利润核对／还原、A03 累计转单季、A06 的扣非利润率配置。年度扣非不再必交季度表。A02 优先核对披露调节表与合计，作者另有调整口径时单列“作者调整利润”，不能与披露扣非同名。

**新增验证：**税前非经常项误作税后归母金额；分类有例外；只有年度数据仍可完成扣非；Q2缺Q1不能计算；资产负债表拒绝累计差分；季度差分跨重述版本拒绝直接拼接。

### M04 杜邦五因素分解

**现有内容：**税负、利息负担、经营利润率、资产周转、杠杆及乘积，使用扣非净利润，并允许缺期初时取期末。

**问题：**扣非净利润／税前利润不宜直接标成通常意义的税负因素；父公司归属利润、总净利润、权益范围混用会改变解释。缺期初自动退到期末，改变平均余额口径。乘积与重复计算同一乘积相等，不是独立 ROE 核验。

**处置：**保留 A07 作为有独立意义的分解方法；可复用 A06 的固定指标配置。分别定义一致口径的标准变体与作者调整变体，不强依赖 A02。直接 ROE 与五因素乘积独立生成证据；分母为零及不适用情况明确交回。

**新增验证：**总权益与归母权益错配；扣非变体误标；缺期初；EBIT／税前利润为零；输入被换但乘积仍相等。批量算五因素，不新增五轮模型。

### M05 偿债压力与流动性体检

**现有内容：**流动比率、速动比率、现金短债比、Altman Z、流动性缺口和风险级别。

**问题：**比率、经验模型、现金压力情景被混成一项。速动资产、受限现金、短债分母未充分区分；Altman 适用样本和公式变体需要固定。只交风险文字不证明完成压力测试，缺少到期现金流和情景输入。

**处置：**常规比率入 A06 的独立配置；R01 Altman 模型单列。流动性压力组合 C04 必须增加有日期的债务与现金情景，未补齐前只叫“流动性指标检查”，不宣称完成压力测试。不得把非空风险等级当成熟评分体系。

**新增验证：**受限现金；零负流动负债；短期借款与一年内到期债务范围；模型版本／行业不适用；缺到期表不能交“缺口已测”。

### M06 营运资本与现金周期

**现有内容：**DIO、DSO、DPO、CCC，另交营运资本周转率。

**问题：**年度365天直接用于其他期间会错；销售、赊销、采购或成本的替代关系未清楚区分；只核 `CCC=DIO+DSO-DPO` 不保证三个天数正确；营运资本周转率输出的定义不完整。

**处置：**O03 周转天数，按存货／应收／应付冻结三个配置；O04 CCC 组合运算。平均余额、期间天数、分母代理规则写明。营运资本周转率待定义后加入 A06，不能保留一个无口径的必填数。

**新增验证：**季报期间长度；期初缺失；现金销售与赊销代理声明；采购额代理；负CCC合法；三个分项有误但加总正确的反例。

### M07 收益质量与自由现金流

**现有内容：**经营现金流／净利润、经营现金流减资本开支、应计比例及质量／异常判断。

**问题：**把 `OCF-CapEx` 一概命名为 FCFF，会被 M14 误用；现金流分类、利息和税等口径需要处理。作为核对参照，Damodaran 的企业估值章节从税后经营利润、折旧、资本开支和营运资本变动构造FCFF，并解释其与融资现金流的边界：[Firm Valuation，第15章](https://pages.stern.nyu.edu/~adamodar/pdfiles/valn2ed/ch15.pdf)。简单应计比例也不等同经过估计的操纵性应计模型或财务真实性结论。

**处置：**A06 中分别定义现金利润比、经营现金流减资本开支、应计比例。将现有 `free_cash_flow_firm` 改为含义准确的新字段，旧字段留历史。真正 FCFF 为 V01。质量解释形成 C03：逐项描述现金与利润差异，引用附注，不凭比例自动判造假或高质量。

**新增验证：**净利润零负数；分母用扣非／原利润的区别；资本开支范围；两种现金流口径不可互换；异常观察不能直接推出因果。

### M08 分部量价拆解

**现有内容：**分部收入占比、销量贡献、价格贡献，缺乏量价时尝试近似归因。

**问题：**分部结构与同质产品量价桥是不同方法；按地区和按产品的收入不能相加。现有占比来源检查未覆盖全部归因公式。收入／销量推得的均价可能混入产品结构变化，不能直接称纯提价。

**处置：**O01 分部结构与变动，O02 同口径量价分解。O02 明确交叉项归属：现候选方式为 `ΔQ×P0` 与 `ΔP×Q1`，两者合计等于收入变化。没有可靠销量／价格则交未完成；可选隐含均价观察必须标明结构影响，不冒充已识别价格因果。

**新增验证：**P0=10、Q0=100、P1=12、Q1=120时，收入增量440、销量贡献200、价格贡献240；换计量单位；多维重复统计；缺销量；产品组合改变。

### M09 客户与供应商集中度

**现有内容：**前五大客户／供应商占比、关联关系及重合观察、风险级别。

**问题：**客户分母是对应销售范围，供应商分母是采购范围，不能都用营业收入；当前客户来源核验强于供应商。关系、重合、风险等级的结构化证据不足，匿名编号不能跨期当同一主体。

**处置：**O05 前N集中度，客户和供应商为明确配置；关联交易使用 R04。客户／供应商交叉识别作为有稳定主体标识时的组合观察，不能由相同占比或匿名排序推断关联。C05 组合呈现事实及限制。

**新增验证：**采购分母误用营收；匿名客户不能做跨期追踪；前N不足N的披露；集中度上升不自动等于议价能力下降。

### M10 资本开支与产能周期

**现有内容：**资本开支／折旧、在建工程转固／期初在建、折旧年限调整、产能阶段判断。

**问题：**转固／期初在建可能超过100%，不是概率；期初为零必须处理。资本开支可能含无形资产，折旧可能只含固定资产，范围未必匹配。折旧年限变动不能直接归为追溯重述；单凭这两个比率不能判断产能利用率和项目周期。

**处置：**资本开支强度进入 A06 的明确配置；O06 在建工程变动桥；O07 折旧估计变更观察。C06 要判断产能阶段，另需项目投产、设计产能、实际产销量及期间，不以比率代替。会计估计和差错更正的处理按适用准则核对。

**新增验证：**当年新增在建使转固比率大于1；无期初在建；折旧与摊销范围；估计变更与重述分别有证据；无产能数据只交资本投入观察。

### M11 研发投入资本化效能

**现有内容：**研发强度、资本化率、专利及新产品产出、转化周期。

**问题：**前两个比例可定义，转化周期／效能没有足够的项目、时间和公式契约。同期研发与专利数量不能直接建立因果。资本化对利润的影响不是天然非经常损益，不能无条件送 M03 扣除。

**处置：**研发强度和资本化率进入 A06 的分立配置。O08 研发项目投入产出观察保留为待补证候选，需项目批次、投入年、产出年和归因限制。研发费用化敏感性若新增，应独立明确摊销、税和资产影响，不偷偷扩充扣非定义。

**新增验证：**总研发支出与费用化支出区分；资本化率分母；研发为零；产出滞后；没有项目数据不交“转化效率”分数。

### M12 CAGR 与趋势外推

**现有内容：**正文有三年／五年 CAGR 和对数线性趋势；输出固定 `_3yr`，营收验收公式固定 `1/3`。

**问题：**明确的正文—契约冲突。CAGR、同比变动、回归趋势不是一个方法；端点不适用却要求数值输出也会迫使填假数。未来外推不能仅靠“参考线”称呼就当成历史事实。

**处置：**A04 期间变动，A05 CAGR；P03 对数趋势拟合另列待补证候选。A05 参数是指标及实际期间间隔，不是“有几行数据”；基期非正等不满足所选定义时输出不适用及原因。原单季预测使用 P01，不能在转介文本中一律指向 M13。

**新增验证：**100→121、两年为10%；三年／五年分别验证；端点为零负值；中间缺年不伪造走势；季度与年度间隔不能混用；未请求趋势时不强制生成趋势表。

### M13 三表联动财务预测

**现有内容：**未来两个季度、三种情景的利润表／资产负债表／现金流表及区间；以杜邦和CCC作为主要上游。

**问题：**三表建模是组合方案。杜邦和CCC不足以供给完整期初表、税、资本开支、融资、分红及运营假设。平表可验证算术闭合，不能证明预测假设合理；现金或短债 plug 不能掩盖未解释的缺口。假设表尚不足以明确所有数值与期间。

**处置：**保留为 C08 三表情景模型模板，先补齐模型规格，再建立 P04—P08 的运营、营运资金、长期资产、融资及报表联动候选。循环依赖（如利息与融资）须有作者接受的求解办法，不能让模型反复试数到平。

**关键区别：**它不是现有财务专家的“季节性同比+最近四季回测”。不能借 M13 之名替换原算法，也不能把两个季度预测无说明地扩成多年DCF基线。原算法另外落为 P01、P02。

**新增验证：**假设数值可追溯；三表传导；余额闭合与业务合理性分开；融资缺口保留；情景顺序；循环求解边界；预测期与估值期不匹配时拒绝直接绑定。

### M14 DCF 估值

**现有内容：**FCFF、WACC、永续终值、企业价值／股权价值／每股值、敏感性。

**问题：**一个完整组合模型被作为单个原子候选。M13实际输出不直接保证FCFF；现有检查重点覆盖股权桥和每股除法，未完整限定FCFF、折现、终值及参数。正文的敏感性要求也不能靠一个泛化表格字段保证。企业价值减净债务是简化桥，不能无条件覆盖所有非经营资产及其他权益索取权。

**处置：**V01 FCFF、V02 权益资本成本、V03 WACC、V04 现金流折现与终值、V05 企业价值到权益及每股桥；敏感性作为 C09 对已定模型重复取值的组合操作，复用同一计算定义。统一币种、名义／实际、税、时点、现金流对象；永续模型须检查折现率与增长率的适用域。

**新增验证：**FCFF与OCF-CapEx不可无条件互换；WACC权重及税处理；终值适用条件；负现金流；季末／年末及分数期间；现金和净债务不重复调整；敏感性格点完整且每点可复算。不得把模型值称“真实内在价值底线”。

### M15 相对倍数与历史分位

**现有内容：**PE、PB、EV/EBITDA、历史分位、可比公司和隐含市值，实际输出和检查偏向目标PE/PB及一个乘法。

**问题：**观察倍数、选择比较基准和反推估值是三个不同职责。扣非年利润不自动等于TTM利润；负利润也不能自动转PB／PS而不解释适用性。历史分位缺时间窗、频率和并列值处理，无法稳定复算。

**处置：**V06 观察倍数、V07 历史分位、V08 同口径比较、V09 给定倍数的估值情景。C10 组合中，样本、基准倍数、日期与选取依据明确，不把AI选了一个倍数当作作者已经接受。该能力不自动加入现有财务专家。

**新增验证：**年度／TTM混用；价格日期与财报披露时点；负利润／负净资产；复权及股本变化；并列分位；可比样本不足；反推市值不混称已披露事实或目标价。

### M16 质押、减持与关联交易

**现有内容：**股权质押、减持计划、关联交易及异常评分。

**问题：**三类证据与事件生命周期不同。质押占公司总股本与占持有人持股量不能混称一个比率；减持计划不等于已经减持。没有质押条款不能假定平仓价；风险分数缺少规则和可验证来源。

**处置：**R02 质押暴露、R03 减持计划与实施核对、R04 关联交易暴露。组成 C11。未知条款交未知；压力情景若需要，必须标为用户／作者设定假设。关系认定基于披露和可核对主体，不凭名称近似或资金往来直接断言利益输送。

**新增验证：**两种分母；解除质押；计划／实施／届满区分；重复公告；未知平仓条件；关联关系证据缺失。

### M17 商誉与资产减值压力

**现有内容：**商誉占比、业绩承诺完成率、全额减值情景。正文明确不做正式可收回金额评估，但输出必填 `cgu_recoverable_amount`。

**问题：**明显自相矛盾。承诺完成率没有对应完整交回；泛称存货、坏账等资产质量，也未提供这些方法。一个 identity 收据不能证明压力情景按正确税和归属口径传播。

**处置：**R05 商誉暴露、R06 业绩承诺对照、R07 指定减值冲击情景。C12 只作情景而非正式减值认定，删除新定义中越界的可收回金额必填项。真正可收回金额测算如要增加，另做完整方法，不把缺项填零。库存、应收减值不能用商誉方法代替。

**新增验证：**负净资产；业绩承诺调整口径；税与少数股东影响；冲击损益及权益一致；正式估值缺失时仍可交情景、不可交确定减值结论。

### M18 审计意见、关键审计事项与或有事项

**现有内容：**审计意见、KAM、担保／诉讼及风险解释。原文引用检查有基础，但 KAM 至少一项。

**问题：**三类内容应分别选择。KAM数量不能凭硬性最小条数保证；无可报告事项或适用边界需要区分“未查到”和“明确没有”。审计意见、强调事项、KAM不能互相冒名；担保比例也需明确范围与分母。

**处置：**R08 审计意见识别、R09 KAM原文提取及对应、R10 或有事项披露整理；担保比例入 A06 的独立配置，C13 汇总。KAM计数由实际条目派生，允许有证据的零项或不适用；不因有KAM就推断报表有错。

**新增验证：**无KAM／未读取完整报告分别处理；强调事项不等于非无保留意见；同一事项重复；原文存在但摘要含义扩大；担保余额／额度／发生额混用。适用审计准则的零事项边界在定型前补核权威原文。

### M19 竞争壁垒与投资假说

**现有内容：**ROIC-WACC、多年持续性、四类壁垒、强弱评级及投资假说。主要上游是杜邦结果。

**问题：**杜邦不能提供完整ROIC与WACC。正利差是观察线索，不能直接证明壁垒；三年阈值也不是普遍证明规则。评级标准、证据矩阵和缺项处理不够完整，“买入假说”超出目前专家承诺。

**处置：**E01 ROIC、E02 资本回报利差序列、E03 竞争证据整理、E04 结论／假说与限定证据对照，组成 C14。WACC复用V03。假说写为可检验的经营判断；评级若保留，需作者明确的量表，不假冒某研究机构评级。

**新增验证：**投入资本的现金／商誉／租赁口径；ROIC与WACC币种期间；单年正值不能冒充持续；缺年不默认弱壁垒；反证保留；相关性不作为因果证明。

### M20 综合财务与估值底稿成稿

**现有内容：**硬绑定五个上游方向、覆盖表、报告和至少三项风险。

**问题：**主要是组合与交付设计。硬绑定DCF等会让简单题跑全链；未绑定的其他方法也不能因“总装有20项”就认为进入报告。要求三项风险容易凑数，源引用存在不等于报告结论被支持。

**处置：**改为 C15 报告组合模板：依本题交付要求和已选有效结果编排证据索引、正文、缺项和限制。文件落盘是运行机制；若作者有独立的论证组织方法，可以另行定义，不能把“写.md”本身当财务原子方法。报告仍遵守作者的交付承诺。

**新增验证：**纯年度题不拉入DCF；预测未完成不得写已完成；无已识别风险不得编三条；未选方法不填结果；数据不平及缺项可进入限制说明；文件内容、成果记录、下载一致。

| P01 | 季节性同比区间预测 | 同口径季度序列、目标期、原4/8季窗口 → 点值和区间、完整计算证据 | 从现有财务专家继承，不是M13 |
| P02 | 滚动起点回测 | 已定预测方法、每个起点可得序列、实际值 → 逐期预测与实际对照 | 从现有财务专家继承 |

这是一份 **45 个职责定义的首轮建议**，不是45次模型调用，也不是一位专家必须装45项。A06/O03/V06 等还需逐配置完成业务契约；最终数量可在样例验证后合并或拆分，但不能靠扩大参数自由度隐藏不同口径。

### 5.2 A06 的第一批指标配置

至少分别写清：毛利率、归母净利率、扣非利润率、平均归母权益ROE、现金利润比、人均创收、OCF减资本开支、应计比例、流动比率、速动比率、现金短债比、资本开支／折旧摊销、研发强度、研发资本化率、担保暴露比例。

这些不是一个输入完全相同的“万能方法”。每个配置有自己的数据要求、单位和不适用域。作者界面可以直接选配置；运行目录若用一个定义承载多个配置，编译时必须把允许的配置集合冻结，不能把任意公式参数开放给运行模型。

人均创收明确期末人数还是平均人数；有值但缺人数不能靠财务表猜。经营现金流／净利润等在分母非正时，是交有符号比值并警示还是不适用，应逐配置定型，不能统一用一个全局正数规则。

### 5.4 真正落成一个方法的样例：A05 CAGR

下面是要交给作者核对的业务规格，不是声称现有API已经接受的请求JSON。

| 项目 | 建议规格 |
| --- | --- |
| 独立问题 | 一个明确指标在两个可比年度之间，复合年均增长率是多少 |
| 必需输入 | 同主体、同币种与单位、同报表范围的起终年度值及证据；起终年份；重述口径选择 |
| 参数 | `metric`、`start_year`、`end_year`；第一变体仅做完整年度，`n=end_year-start_year` |
| 做法 | 核相容性和 `n>0`；第一变体要求两个端点为正；按 `(end/start)^(1/n)-1` 计算，保留足够精度 |
| 不做 | 不自动补另一指标，不自动回归、不预测未来、不因中间缺年虚构逐年走势 |
| 输出 | 主体、指标、起止年、n、两个输入引用、结果、compute_id、口径、状态及原因 |
| 缺项 | 没有端点为missing；年份／版本冲突待解决；不满足定义为not_applicable，不能返回0代替 |
| 验收 | 年份差与n一致；输入身份和单位一致；公式及操作数与收据一致；值在该配置容差内 |
| 独立例子 | 合成值2021=100、2023=121，n=2，结果0.10；把n改3须拒绝 |
| 复用证明 | 年度财务分析模板和研发投入增长模板分别调用；方法定义不含任何固定专家或步骤ID |

精确复核应使用确定性十进制／数值计算能力，展示百分比的舍入不反过来污染计算证据。若未来允许起点为正、终点为零的特定定义，另明确边界后发布新配置；不让模型自行决定是否把它算成-100%。

### 5.5 组合需要比“连上线”多什么：C07示例

1. 作者先接受预测公式、允许的指标、4/8季窗口、回测范围及数据质量规则，形成组合的固定语义。
2. 实际题目给出目标季度。计划反推上年同季基数、同比所需的前期季度，以及每个回测起点的独立窗口；不是仅检查“总共有16个季度”就认为足够。
3. 原始累计数据先经A03产生单季，已有可信单季则不重复差分；A04构造相容的同比序列。
4. P02在四个历史起点分别调用已钉版的P01逻辑，所有起点禁止读取当时不可得的输入。P02是对指定预测方法的受限回测，不是允许运行模型传入任意新算法。
5. P01对本题目标季度计算点值与上下界。保留原作者方法：上年同季乘以一加近4季同比中位数；上下界使用近8季同比最小／最大值。回测合格与否、能否继续，服从作者明确规则，不由模型临时降门槛。
6. 最终成果按“指标×目标期×点值/上下界”和“指标×回测期×预测/实际”验覆盖；缺哪一格就说明哪一格，不能把有个horizon=2当作交齐。

在工程上，P01/P02的关系可先使用明确的输入输出及共享确定性预测实现，不需要支持任意方法调用任意方法的递归运行。模板展开后的任务计划仍是有限、可检查的计划。

## 六、组合化：保留研究方案，形成可加工的创意模板

组合模板保存：用途、默认选中的方法与配置、依赖映射、必做／条件选规则、数据需求、交付约定。作者能删改和补入原创方法；模板应用后进入创意工作稿。首版复用现有创意／模板机制，不建设递归组合市场或独立组合运行服务。

### 6.1 对同一位财务专家的三个实际计划示例

**完整年度分析加季度预测：**题目与范围确定 → 所需事实及原文授权／准备 → 作者要求的Q01—Q04 → A03单季还原 → A04/A05/A06题定指标 → P02最近四季回测及P01两季预测 → E04管理层讨论核对 → C15报告。管理层讨论具体依赖哪些结论、何时执行由作者确定；没有理由为此增加DCF、质押或Altman。

**人均创收：**题目范围确定 → 收入与员工数据、相关原文 → 必要数据质量核验 → A06人均创收配置 → 按作者规则选择E04 → 报告。员工数缺失，提出真实缺项或按已有规则交局限；不去要四年季度报表，不跑单季还原、预测和回测。是否缩减四式范围是作者内容变更，不能由优化自动决定。

**另一家A股年度营收：**主体与期间确定 → 对应主体实际授权数据 → 必要核验 → A04及走势描述 → 报告。未授权不能读取，原专家范围不覆盖则交用户决定；不能借“通用模型有常识”制造财务数字。

此外，问DCF或股权质押时，仅当这位专家新版明确接受了相关方法与声明范围，才可执行；市场上存在这些模板不等于它已经具备这些能力。

## 七、数据契约：让每个方法真的拿得到输入

### 7.1 分开四类输入

| 类型 | 示例 | 要求 |
| --- | --- | --- |
| 披露事实 | 营收、资产、员工数、股本 | 原始出处、主体、期间／时点、范围、单位、版本、披露时间 |
| 推导事实 | Q4收入、平均权益、同比 | 输入事实或上游成果引用、公式变体、compute收据、精度 |
| 假设参数 | 增长率、资本成本参数、情景税率 | 参数值、由谁提出／接受、依据、适用期；不能伪装成披露值 |
| 质量与约束 | 勾稽未平、原文缺失、重述不一致 | 哪个事实／结果受影响、是否允许继续、采取哪条作者规则 |

建议的业务输入样式如下；优先映射现有 FactRequest、事实引用和成果契约，不新增同名的第二套事实库：

```yaml
subject: 600519.SH
metric: revenue
period: {start: 2024-01-01, end: 2024-12-31, kind: annual_flow}
statement_scope: consolidated
currency: CNY
unit: yuan
value: "..."  # 金额以十进制保真；这里不提供示例真数
source: {material_id: "...", version: 1, fact_ref: "...", page: 63}
disclosed_at: "..."
revision_basis: as_reported  # 或明确重述版本，不能只写latest
status: available
```

计算与原文可以是不同但相互可核对的证据。不是所有市场数据都具有PDF页码；Wind结果保存查询、字段、期间、供应回执和版本等实际证据。要求核原文的结论仍需对应报告原文，不能把Wind数值回执伪造成页码证据。

### 7.2 依赖的两条线

**数据线：**收入与成本 → 毛利率；季度序列 → 同比 → 预测。

**质量线：**某期间勾稽结果 → 是否允许该期间进入某种预测。

方法输入既可来自已授权事实，也可来自另一方法的结果。M02的“已平衡”不能当作营收金额，M04的ROE不能当作股东质押公告。每个必需槽必须能找到明确的生产者；绑定时校验类型、期间、范围、单位和可用状态。

保留数据准备和方法执行的分工：准备阶段根据所选方法汇总初始需求；执行发现真实缺口时走补充需求与确认，不把数据理解成只发生一次的第0步。

### 7.3 供应顺序与可得性

沿用所有者已说明的顺序：**用户确认需求 → 使用有权访问的知识库数据 → 缺项优先尝试适用且获准的Wind能力 → 再使用巨潮等适用来源。**这不是把所有数据都强行送Wind：财务字段、报告原件、公告和市场时间序列要按供应能力选源。

只补缺失的事实或读法；已有原件缺结构化加工，不应无意义重采同一原件。waiting必须有实际加工或采集状态依据，不能仅凭未过期确认记录宣称在取。任务停止、供应是否继续及费用各按现有授权状态处理，不能因本方案自动重启。

回测绑定每个预测起点当时可得的数据。后期重述值若被用于历史回测，必须明确是事后重构评估，不能冒称当时可实现结果。报告期、披露日、任务日是三个不同维度。

## 八、验收改造：核对正确做法，也允许真实坏消息

### 8.1 结果与执行分开

建议在现有交回物内表达业务状态，不立即新增一套平台状态机：

- `computed/observed`：完成计算或证据观察。
- `missing`：必需事实／证据缺失，说明缺哪一项。
- `not_applicable`：有事实但方法适用条件不成立。
- `unverified`：不能完成要求的验证。

勾稽结果另有 `balanced/unbalanced`，结论对照另有 `支持/不支持`。这些是不同含义：**算出了不平 ≠ 平台出错；未核验 ≠ 已平；原文不支持 ≠ 计算一定错。**

有效不平结果交给专家质量规则决定后续，而不是不断重试直到算成零。无效结构、篡改计算或错误来源仍须拒绝。若“缺数”导致题目没解决，任务可以有诚实但不完整的成果，不能把方法正确交回缺项当作整题成功。

### 8.2 每个定义的六类检查

1. **结构：**字段、类型、唯一键、状态与数值是否一致；不强制用假数填满表。
2. **语义输入：**主体、期间、单位、合并范围、版本及适用域相容。
3. **计算：**本任务收据、固定公式、关键操作数、结果与容差；金额、比例、天数分别定义容差及展示舍入。
4. **证据：**事实可读取、引文原话存在、授权和版本正确；原话存在与结论得到支持分别检查。
5. **覆盖：**题定输出及实际需要的期间都处理，缺项须逐项说明；不是把全部授权材料都强制加入覆盖集合。
6. **交付：**已执行、未执行、不适用和失败结果能在最终报告区分，文件与成果记录一致。

工程上先复用现有 `computed/input_keys/sourced/quoted/covers`。现有 `_computed` 已能核公式语法树和报告操作数，但这还不能独自保证所引事实属于正确主体期间；输入绑定与证据层要补相应检查。不能简单删除所有精细验收，也不能用关键词命中“不提供目标价”就判成提供目标价。

### 8.3 独立测试，不再只从被测公式生成期望

每个新定义至少提供：手工可核算的正例、适用域边界、缺项例、错误公式／操作数例、错误来源／期间／范围例。非数字方法提供原文支持、部分支持、反证和没有对应内容的例子。

重点案例：

| 类别 | 必须拦截或正确表达的反例 |
| --- | --- |
| 四式 | 用A=负债和权益总计替代缺E；用现金流量作期初余额；残差非零却报平 |
| CAGR | 五年题仍用1/3；年度行数代替年间隔；零负基期假算 |
| 季度 | 缺H1却推Q3；不同重述链混减；资产负债表作差称单季 |
| 杜邦 | 归母利润与总权益错配；重复算同一乘积冒充独立验证 |
| 预测 | 跳过原回测；历史起点使用未来数据；区间上下界错位；将历史范围称统计置信区间 |
| 估值 | CFO-CapEx直接冒充FCFF；不满足终值域；净债务和现金双重调整 |
| 证据 | 引文存在但只支持半条结论；不同口径方向相同就判支持；来源另一公司 |
| 无发现 | 没有KAM／重分类／三条风险而编造条目；把未查到等同不存在 |
| 计划 | 年度营收题强制DCF；人均创收题强制季报；依赖未满足仍放行 |

业务结果期望应由独立算例或明确原文先写，再对实现核验。合成数据标明合成；普通测试只读比对冻结快照，更新golden用独立显式命令。真实案例与模型回归在另行授权后执行，不继承旧轮预算。

## 九、开发落点与执行次序

### 9.1 不另起炉灶的实现边界
