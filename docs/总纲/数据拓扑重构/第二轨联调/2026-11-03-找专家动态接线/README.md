## 修复行为

“让AI找”先提交新会话、再建任务，同请求重发时新session参与摘要造成409并留空会话；
并发重发会撞唯一约束。电脑离线或驾驶命令入队失败时也可能留下半次受理。
现以本人项目行锁串行核幂等，所有本地受理写入同事务提交；重发查回原session/task，
预算改变报冲突，排队与已取消任务不被重试复活。原task_key/响应结构保持。

网页原来每次挂载生成随机委托键，刷新找专家结果页可能再建一笔委托；改用该轮task
生成稳定键（幂等作用域另含用户/专家版本）。自动请专家出错可显式重试，不自动循环，
失败不再同时显示正在请。付费候选仍须点击，无匹配的直接答/结束/孵化入口保留。
