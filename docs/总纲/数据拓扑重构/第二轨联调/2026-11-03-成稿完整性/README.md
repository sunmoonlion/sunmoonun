# 成稿读取完整性（2026-11-03）

## 发现与修复

`AgentDeliverableCheck.read_bytes` 原先接受读取响应而不核对实际字节数、声明文件大小与
结束标记。文件读取中途变化或响应不完整时，半份内容可能被标为完整测试成稿；没有验收
摘要的旧兼容链也可能将其写入资料库。旧 link 的摘要回退会对这半份内容计算哈希。
本次由故障注入复现，未发现或声称线上已发生这类损坏。

现要求非负整型 size、合法 Base64、实际字节数等于 size；如果带 eof，必须为 true。
错误走既有 AgentServiceFailed：归档保留重试，测试成稿读取保留失败原因，摘要回退返回
未知而不记录错误摘要。完整空文件和不带 eof 的旧响应仍可读取。大小上限不变。

## 工程证据

- 修复前：12 个错误响应回归全部失败，见 before.log；包含截断、大小不符、非法编码与字段。
- 修复后：文件读取、产出归档、动态专家测试导出、证据到成稿共 66 passed，48.89s，见 after.log。
- 隔离数据库验证有/无验收摘要两种场景：首次截断不写资料库，等待重试，恢复后原样写完整内容。
- ruff、pyright 通过；模型、文件服务及资料库响应使用替身，没有线上 Wind 调用。
