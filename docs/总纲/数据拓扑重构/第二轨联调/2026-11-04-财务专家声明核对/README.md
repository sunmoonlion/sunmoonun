## 配套运行器修复

旧提示明确写着“partly covered question is NOT out of scope”，并允许无回答时作假设继续，这是误接问题的直接诱因。现在：

1. 查找明确排除“唯一/免费就适用”、把指定方法降为可选、用相关数据替代所需方法。目录快照、实际声明引句和确定版本校验保持；不把这些结构校验说成语义证明。
2. 在现有定数据轮次内先核范围，不新增收费预判轮。模型报告必要要求超范围/关键歧义时，取消本尝试、记实际费用、进入等待输入；不将空采单标为ready，不启动后续分析。正常缺数据仍进入既有确认流程，不误判为方法不适用。
3. 只在模型给出具体可承接的缩小后问题时显示“接受上述范围继续”。用户明确点击proceed后，范围调整随记录传至后续步骤；停止、重做、过期、无回答都不等同接受。无具体子问题仅可停止本委托，回入口改题、选其他专家、通用模型或提交创意。历史已消费的旧版明确proceed记录保留语义。
4. 定范围与成稿使用既有each_has/all_equal/list_min/covers/list_empty验收模板，无新增契约、迁移或金融算法。成稿漏项、重复项、要求编号替换、空答案、明确未完成均拒绝通过。
