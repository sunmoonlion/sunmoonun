# 财务分析与预测智能体验收题单（V0 金标准与算式映射）

> 依据《财务智能体双轨交付计划》第 15.4 节 WP-1 规范制定。
> 作为 M0 基线固化与新契约专家重孵化后验收的真源标准，严禁使用纸面模糊承诺或未经审计的口径。

## 一、标准与误差门禁

1. **绝对金额指标**：允许误差为 `0`（与官方披露原件审计报告经 Decimal 转换后完全一致，单位统一为元或百万元并在输出中标明）。
2. **比率与相对指标**：允许误差小于 `0.01%`（即 `0.0001`），以四舍五入到万分位为准。
3. **复合年均增长率 (CAGR)**：采用确定性计算工具的分数次幂 `((end / start) ** (1 / n)) - 1`，严格取 4 位小数（如 `0.1719`），禁止大模型自由估算。
4. **数字追溯链**：每一个输出数值必须同时返回来源原件的三元组 `{material_id, content_version, digest}` 及报告期和科目编码。
