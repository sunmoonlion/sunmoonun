## 复核项与修复

- P1-1：M04 与 M20 都使用含 metric 的对象索引，声明 source_field；当前编译器零错误，
  正常杜邦产物不作字符串转换直接进入 M20 验收。M20 五个上游分别 covers，不遗漏其他上游。
- P1-2：通用 computed 增加 expected_value，计算结果及交回值均需满足零差额容差；
  M02 核期初/期末平表、留存收益、现金变化及跨期期初对应。999999 的真实计算结果与
  同 ID 伪装两侧相等均被拒绝，反例中其他字段保持有效。
- P1-3：M13 明确两个相对期次、三情景、指标最低覆盖与联合唯一性；资产负债表、现金流
  表和区间的数值列通过 input_keys 直接绑定本任务计算记录的操作数。
  空表、重复行、非零配平和篡改数值但借用正确证明都会失败。
- P1-4：意见/KAM 以受枚举限制的记录类型强制引文，不再匹配自由文本事项标题。
  另一合法事项标题正常通过；无引文、非法页码、原文不符、伪造类型都会失败。
- P1-5：20 项边界原文保存到冻结 rules/selection，验证冻结→装配→编译后仍在；
  M20 来源标签使用中立输入槽，装到另一个专家、更换本地步骤别名仍有效。
- P2：风险内容/来源非空、内容不重复、来源限于真实输入槽；空白和不存在来源反例被拒绝。

扩展保留在既有 AcceptanceRule/作者编译器中，没有财务专用运行器或资产 API。
新参数在 UI 可编辑，零目标值正常保存；旧规则不序列化新默认字段，旧快照形状保持。
旧运行器拒绝未知参数，不能把“先发新方法、运行器以后升级”当可用路径。
