## 实际行为

- `POST /api/web/v1/method-units/{method_id}/versions/{version}/bind` 复用 `BindMethod`，要求正常 web 身份、CSRF、作者自己的工作稿和正确 revision。绑定/升版只是保存工作稿；正式专家继续经原有出版本、测试和交付流程。预览接口保持只读。
- `method_refs[alias]` 保存方法 UUID、版本、摘要、命名槽连接；绑定对应格子与引用共用作者 copy 证据并原子写入。普通编辑、AI 接受/孵化整稿保存不能改投影或丢引用；改变上游输出使输入失配也拒绝。重新选择版本/组合参数必须走显式绑定。
- 方法首次冻结将默认工具、额度、读入上限和输出结构保存为实际值；作者高级输出结构也作为输入槽约束。改平台默认值不能扩张这些已冻结参数。
- 复制/导入保留引用，检查作者所有权；编译时按确切版本取主档，不读最新版本。篡改定义、摘要、连接、编译工具/契约或使用未知编译器都会拒绝。
- 动态目录升级为 `knowbench/dynamic-methods/v2`，显式 `method_compiler=knowlab/workdraft-compiler/v1`，`method_sources` 含独立方法定义证据。引用单元的 `step_version` 是方法版本。knowmart 保留完整清单，knowbench 校验引用并为任务计划保留冻结快照；编译器仍唯一归 knowlab。
- author-method 定义 schema 未变；新增目录 v2 provider schema、knowlab 消费锁、knowbench author-method 消费锁。孵化请求工作稿增加可选 `method_refs` 并同步消费锁。旧固定 v2 摘要、无引用目录 v1 schema 字节不变。
