# Luna 的专家使用方案

现行设计只分工具方法和专家方法。孵化按待建专家的声明选方法，使用按本题先找现成专家。工作台统一受理、同页拟计划与转 KnowLab 的交互见[使用方案](../../专家使用方案/luna/专家及专家团使用方案.md)，登记、冻结和执行见[方法主稿](../../专家孵化方案/luna/专家方法孵化与递归编排方案.md)。


现行配套：[专家及专家团使用方案](专家及专家团使用方案.md)。覆盖聊天转委托、基准上二次编排、确认页联动重算、执行调整、成果回传与按许可回炉；共同定义引用方法主稿，仍待实施与验收。原财务执行与验收稿不恢复。

[MCP 和 Skill 接入实施方案](../../../mcp和skill接入实施方案.md)：API 注册、runner 范围准备、Codex 暴露与加载、连接授权和恢复；第 11.2 节说明三个入口，当前实施与发布状态只查 §17.6–17.7，不用早期入口发布代替正式方法准入验收。

原稿来源与拆分映射见[孵化目录说明](../../专家孵化方案/luna/README.md)。内容是方案建议，原代码和合成测试证据标明日期，本轮未实施或重新验证财务方法。

配套：[作者孵化](../../专家孵化方案/luna/新财务专家孵化方案.md)、[专家团运行衔接](../../../专家团方案设计/专家团使用方案/luna/协作任务与成果交接.md)。
