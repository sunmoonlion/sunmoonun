# Luna 的专家使用方案

2026-11-14 最新分类：工具方法、专家方法、专家团方法，统一采用五要素两视图和调用治理；工具直接派发，专家及专家团共用编排。按不同专家方法身份和是否依赖专家团确定分类，版本与调用次数不增加种类。定义与验收以[方法主稿](../../专家孵化方案/luna/方法、步骤、组合与模板.md) §1.1、§4.4 为准；本轮仅同步文档，未改代码或协议。


[财务专家执行与验收方案](财务专家执行与验收方案.md)：新首版按题规划、输入与授权绑定、结果证据、独立验收、恢复及旧任务退出；不再以旧版等价迁移为门槛。

[MCP 和 Skill 接入实施方案](mcp和skill接入实施方案.md)：API 注册管理、runner 执行上下文能力准备与交付、Codex 工具暴露和 Skill 加载、统一连接与调用授权、线程与账本恢复及分阶段验收。第 11.2 节细化「连接与工具」「技能」「本次能力」三个前端入口。方案同时适用于聊天、工作和各级方法。2026-11-13 三个入口的首期代码和当前限制见第 15 节；普通聊天／工作已接线，方法新增受管能力绑定仍待实施。首期已于 2026-11-13 经本地 Jenkins #92 发布，外部 MCP 目录为空，发布记录与限制见第 15 节。

原稿来源与拆分映射见[孵化目录说明](../../专家孵化方案/luna/README.md)。内容是方案建议，原代码和合成测试证据标明日期，本轮未实施或重新验证财务方法。
