# 财务专家执行与验收方案

日期：2026-11-14。按[首版孵化方案](../../专家孵化方案/luna/新财务专家孵化方案.md)，新建“财务分析与预测专家”身份，从第一版开始。本文替代旧专家升级与等价迁移路线，描述待实施的运行和验收要求，不是上线或测试通过记录。

方法结构以[方法主稿](../../专家孵化方案/luna/方法、步骤、组合与模板.md)为准；工具提炼另行专项开展，当前只有[提炼示意](../../专家孵化方案/luna/原20个财务方法的工具方法提炼.md)；版本及目录见[市场方案](../../专家市场方案/luna/财务专家能力声明与版本方案.md)。

## 一、受理新首版

用户指定或 AI 按实际能力声明选择新专家。目录必须返回其新身份、精确版本和摘要；没有满足问题的已发布能力时，明确缺项，不退回已退出的旧财务专家，也不将候选工具当作已完成的专家能力。

受理后固定本次版本和问题。工具方法直接派发，专家使用统一编排；运行器不含财务专用八步、公式或投资判断。所需资料、方法和校验由冻结定义决定。

## 二、按问题形成计划并确认

| 环节 | 要求 |
| --- | --- |
| 确定目标 | 识别问题、范围与结果要求；超出声明时明确解释，不临时增加能力 |
| 形成计划 | 依据已孵化工具候选、必做/条件必做规则和依赖安排步骤；每步调用一个方法 |
| 检查计划 | 程序检查版本资格、输入供应、产物、导出及预算；不把模型提出的计划视为已授权 |
| 统一确认 | 同页呈现计划、资料、账号与费用上限，分别记录确认及授权依据 |
| 执行与恢复 | 沿持久计划和调用关系推进，正常展开不耗纠错重排额度；范围扩大重新核验与确认 |

首版可以对不同问题采用不同合法计划，唯一合法计划也可由程序生成。不要求复现旧八步，不以某种预设顺序作为首版验收条件。

## 三、资料、计算和证据

每个步骤的实际输入固定主体、期间、单位、范围、来源版本及必要证据。输入可以来自用户提供、获准资源和已验收的前序成果；不得把一段质量摘要当作计算数值，也不得因模型能读到引用就认为已有访问权。

按确认后的首版方法核对财务含义。缺资料、口径冲突、业务不适用、程序故障和验收失败分别处理；不得补造数据、用不明调整平表或把未执行写成完成。

确定性计算由已冻结实现直接执行，不为每个指标增加模型轮次。需要模型的解释和证据判断使用用户沙箱及其模型，依据已获准材料工作。数值结果与引文分别验证，技术成功不代替业务验收。

算法、预测窗口、容差、评价方法和条件门由新首版作者接受后生效。旧四式、1 元阈值、原预测算法等只作为可核对素材，不由运行器强制继承；采用后不得临时改动。选择回测时必须核对每个评价时点可得资料，防止未来信息进入预测。

## 四、交付与失败处理

专家只通过声明的导出映射交付结果，内部材料和中间成果不自动全部返回。下层方法通过后，上层仍核对整体承诺；已承诺分支失败不能因为结果为空而免检。

报告说明实际覆盖、缺项、假设、方法及来源；未完成的部分不能冒充完整交付。用户要求删除必做项时，按主稿处理退出原专家承诺的后续任务，不把修改后的结果仍算原专家完整履约。

取消、授权失效、范围收窄和失败恢复沿共同机制执行。外部副作用结果不明时不重放；步骤恢复不能静默换最新方法或重新生成不同计划。

## 五、验收新首版

| 验证范围 | 通过依据 |
| --- | --- |
| 问题与计划 | 应选、应拒及条件分支符合首版声明；计划包含必要依赖，无关分析不被强加 |
| 工具结果 | 已确认公式或判据、输入口径、结果与证据正确，缺项与异常处理可复核 |
| 权限与审批 | 真实用户、连接和资源范围可核，父子授权收窄，具体动作批准不被计划确认替代 |
| 交付 | 导出结果满足承诺，文件可读，未完成与限制如实说明 |
| 恢复 | 调用身份稳定，重复回执不重复副作用；取消、撤权和重启后不越权续跑 |
| 成本 | 实际模型轮次、取数、费用和耗时可查，符合本次授权预算 |
| 身份与退出 | 新专家独立钉版；旧身份不能通过目录、安装、恢复或重试继续执行；旧成果可读 |

先用合成输入和受控适配器验证机制，再按授权做真实模型与业务质量验证。测试由作者指定数据和独立预期，证据记录实际计划；测试集答案不进入规划上下文。

以新首版自身承诺判定通过，不设旧专家功能逐项等价门槛。历史题可作为新测试素材，但须重新核对预期。原 99 项探针及旧运行结果仅属历史证据，来源见[提炼示意第七节](../../专家孵化方案/luna/原20个财务方法的工具方法提炼.md#七历史审查与来源边界)。

## 六、旧任务退出与实施边界

旧专家版本及专用执行路径按首版孵化方案第六、七节独立清理。未结束任务不转入新专家、不以旧包继续运行；停止前核对活动尝试和可能已发生的外部副作用，并保留必要结案记录。

历史成果、费用、授权依据及版本标识可以保留读取，但不能恢复旧执行器或把历史快照重新装成可调用包。清理仅针对核定的旧财务专家身份，不能删除全部 expert 会话、共享工具或用户原始资料。

当前未执行上述清理，也未完成新首版定义、模型验证或发布。跨仓实现次序沿方法主稿第 4 节，清理与孵化状态统一记在首版孵化方案和待办中，不另建兼容执行路线。
