# 专家方案设计

现行设计只分工具方法和专家方法。孵化按待建专家的声明选方法，使用按本题先找现成专家。工作台统一受理、同页拟计划与转 KnowLab 的交互见[使用方案](专家使用方案/luna/专家及专家团使用方案.md)，登记、冻结和执行见[方法主稿](专家孵化方案/luna/专家方法孵化与递归编排方案.md)。


所有者 2026-11-09：「专家方案很复杂，你专门做这个，不要并行做了。你写个文件夹专家方案设计，里面分 luna 和 opus，你把你的方案写在 opus 下。」同日改结构：「二级目录设：专家孵化方案；专家使用方案；专家市场方案；三级目录根据助手分」，后又加：「三家目录加argon」，又说明「我们的二级目录其实分别是 knowlab（孵化），knowbench（使用）和 knowmart 的设计」。
