## 三、13 道可执行计算参考题

金额按披露精度精确换算；派生比率使用 Decimal，HALF_UP 保留 4 位小数，单位为比例
（0.1719 表示 17.19%）。测试对已舍入输出要求完全一致；实际作者容差另行显式冻结，
不能把“约等于”默认为零误差，也不能用浮点常数替代原始金额。

| 题号 | 问题/口径 | compute 表达式 | 本轮参考值 |
| --- | --- | --- | --- |
| Q01 | 茅台 2024 营业收入 | `rev` | 170899152276.34 元 |
| Q02 | 茅台 2024 归母净利润 | `profit` | 86228146421.62 元 |
| Q03 | 茅台 2024 营业成本 | `cost` | 13789482367.98 元 |
| Q04 | 茅台 2024 毛利率 | `(rev - cost) / rev` | 0.9193 |
| Q05 | 2021→2024 营收 CAGR，3 个年度间隔 | `(rev / start) ** (1 / 3) - 1` | 0.1719 |
| Q06 | 茅台 2024 经营现金流净额 | `ocf` | 92463692168.43 元 |
| Q07 | 茅台 2024 现金资本开支（上述指定行） | `capex` | 4678712053.56 元 |
| Q08 | 经营现金流减上述现金资本开支 | `ocf - capex` | 87784980114.87 元 |
| Q09 | 茅台 2024 年末资产负债率 | `liabilities / assets` | 0.1904 |
| Q10 | 归母净利润/期初期末平均归母净资产 | `profit / avg(equity_begin, equity_end)` | 0.3843 |
| Q11 | 宁德时代 2024H1 营业收入 | `cat_rev`（先换为元） | 166766833600.00 元 |
| Q12 | 宁德时代 2024H1 研发费用 | `cat_rnd`（先换为元） | 8592452400.00 元 |
| Q13 | 动力电池系统分部毛利率 | `(segment_rev - segment_cost) / segment_rev` | 0.2690 |

Q08 只是指定现金流差额，不自动等同 DCF 中的企业自由现金流 FCFF；估值方法需另行定义
税后经营利润、非现金调整、营运资本与资本开支口径。Q10 使用既有平均净资产口径；
它与年报 A/5 披露的加权平均 ROE 36.02% 不是同一指标，不以相同数值验收。
Q13 原披露毛利率为 26.90%，应按披露舍入精度比对，不能要求显示百分比还原到任意精度。

## 四、异常与动态执行验收题（业务链待实测）

这些题规定验收观察点，未宣称已在生产完成。行业适用范围归作者方法与专家，不写死在
平台通用计算器中；无匹配专家时仍保留通用模型、终止、提孵化请求三种路径。

| 题号 | 输入/情形 | 必须观察到的行为 |
| --- | --- | --- |
| Q14 | 用一般企业模板分析平安银行 | 判断作者目录是否支持银行口径；不支持则说明限制、给替代路径。不能谎称银行没有营业收入 |
| Q15 | as_of=2026-11-02，要求 2026 全年已披露实绩 | 区分未结束年度与预测，不编全年实绩；不写死“最新年报为 2024”，实际已披露范围由查询证明 |
| Q16 | 用同一模板分析保险公司 | 检查方法适用范围；未配置保险口径不得硬套制造业毛利率 |
| Q17 | 用同一模板分析证券公司 | 检查方法适用范围；不得将金融业务科目机械映射成制造业成本 |
| Q18 | 主体简称歧义或同名多证券 | 主体消歧后冻结代码，不能默认选第一项 |
| Q19 | 原件/事实缺失或读工具不可达 | 查询/补采/平台故障分开；缺数不能以空数组通过必需成果验收，取消提问不等于允许编数 |
| Q20 | CAGR 基期为 0 或负数 | 不产虚假 CAGR；按作者规则说明不适用或选获准替代方法。计算器拒绝除零与非正底分数幂 |
| Q21 | 两版本存在重述、合并与母公司并存 | 明确版本、比较期及口径，不拼接不同版本金额；旧任务继续追溯原快照 |
| Q22 | 年报、三季报、半年报、一季报累计转单季 | 利润/现金流按适用方法差分；资产负债表不差分；缺任一必需累计数不能补零 |
| Q23 | 请求未来两个季度 | 记录 as_of、可得数据截止日、目标季度、回测窗口；固定历史回归与真实未来预测分开，不让后见数据进入历史预测 |
| Q24 | 无本地文件但 Wind 已能返回所需事实 | 优先按数据需求选择合法查询，不机械要求重新下载 PDF；方法需要原文页码时仍需原件证据 |
| Q25 | 同一专家接趋势问题与现金流异常问题 | 只在作者已冻结方法中形成不同计划；依赖闭合，不能临时发明方法或强跑全库 |
| Q26 | 问题未选专家 | AI 检索 knowmart；支持用户直接指定；无匹配保留通用模型/终止/孵化，不静默替用户决定 |

## 五、已验证与未完成

- 自动化：13 题经真实 KnowbotCompute 与数值验收函数执行（仅事实读取替身）；逐题核对
  固定参考结果，拒绝错数与空结果；缺失事实不能留下成功计算记录。
- 通用工具修复：小数字面量从源码转 Decimal，公式等价比较不再受 float 舍入影响；
  数值序列化不受调用方 Decimal 精度影响。另有高精度、除零、非法表达式与公式错配回归。
- 未完成：第二人原件复核、作者接受、Q14～Q26 完整业务实测、真实资料授权/relay/Wind
  服务端读取/页码验收/成稿闭环。13 道工程题通过不抵消这些待办。
- 验证原件保留公开链接与摘要，不将供应商完整响应或授权凭证写入 Git。
