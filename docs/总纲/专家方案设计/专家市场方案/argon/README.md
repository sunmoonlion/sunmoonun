# argon 的专家市场方案（knowmart）

本目录存放 `argon` 独立编写的 `knowmart` 专家市场、能力声明与版本治理方案设计稿（基于仓库一手契约、领域代码与所有者决定独立完成，定稿前不动代码）。

## 文档导航

- **[专家市场方案：统一能力声明卡、双层清单隔离与版本演进治理](专家市场方案.md)**
  - **一、核心定位与四大市场治理原则**：明确「一人一小店」、统一 8 栏结构化能力声明卡、公私双层清单隔离、固定与动态专家并存及两道关合规审核。
  - **二、统一能力声明卡规范（8 栏结构化能力声明）**：详述平台只读头信息与作者必填的 8 栏能力卡结构（目标与结果、适用范围、方法边界、数据前提、交付形式、不适用与不承诺、条件不足处理、正反示例），解除能力声明与测试状态及动态规划的耦合。
  - **三、双层清单隔离架构**：`KnowbotManifestV2/V3` 私有执行包与 `knowmart/expert-directory/v2` 公开目录投影的严格隔离，防止私有方法资产泄露。
  - **四、版本演进与「固定财务专家 vs 动态财务专家」并存方案**：设计双条目并列上架与单条目内版本递增、摘要不可变的演进规则。
  - **五、上架审核、绑定数据许可硬查与下架治理**：自用（`self`）与公开（`public`）双档、`FrozenBinding` 许可巡检（`HOLD_REASONS`）以及正常下架 vs 违规紧急撤回的运行边界。
  - **六、待所有者拍板确认的事项**。
