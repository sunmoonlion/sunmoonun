# Luna 的专家市场方案

现行设计只分工具方法和专家方法。孵化按待建专家的声明选方法，使用按本题先找现成专家。工作台统一受理、同页拟计划与转 KnowLab 的交互见[使用方案](../../专家使用方案/luna/专家及专家团使用方案.md)，登记、冻结和执行见[方法主稿](../../专家孵化方案/luna/专家方法孵化与递归编排方案.md)。


现行配套：[方法市场方案](方法市场方案.md)。覆盖一套机制三个入口、目录视图、组合与运行资格、实际使用费用、运行时选择和版本撤销；共同定义引用方法主稿，仍待实施与验收。原财务能力声明与版本稿不恢复。

原稿来源与拆分映射见[孵化目录说明](../../专家孵化方案/luna/README.md)。尚未查询线上市场、授权和交易记录，不能据此执行版本或数据库清理。

配套：[孵化](../../专家孵化方案/luna/新财务专家孵化方案.md)、[团队市场衔接](../../../专家团方案设计/专家团市场方案/luna/团队声明与成员版本.md)。
