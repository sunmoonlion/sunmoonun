# argon 的专家孵化方案（knowlab）

> 当前分类以[方法主稿](../luna/方法、步骤、组合与模板.md)为准（2026-11-14）：工具方法不调用其它方法；专家方法组合工具及零种或一种专家、不含专家团；专家团方法调用两种或以上专家，或已有专家团。按方法身份及冻结允许依赖分类，三类共用契约和调用治理；专家与专家团共用编排。以下历史正文、旧协议或评审结论保留原时点含义，“两类”“不设专家团类型”及独立团队引擎等旧表述不作为当前目标。


本目录存放 `argon` 独立编写的 `knowlab` 专家孵化方案设计稿（基于仓库一手契约、领域代码与所有者决定独立完成，定稿前不动代码）。
