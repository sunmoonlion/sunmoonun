# 原 20 个财务方法的工具积木与模板骨架提炼

2026-11-19 按[方法主稿](专家方法孵化与递归编排方案.md) §2.6、§3.2.1、§3.3、§4.2–4.4 修订。历史素材来自 sunmoonun 提交 `8261d1b6e` 的《原20个财务方法的原子化提炼》。来源范围见[历史审查与来源边界](#六历史审查与来源边界)；采用哪些问题作为首版承诺，见[新财务专家孵化方案](新财务专家孵化方案.md)。

## 一、从旧方法提炼工具候选与组合候选

M01–M20 提供计算、识别和组织工作的方法素材。下表中的 A/Q/O/V/R/E/P 编号与英文短名只供讨论。A06、O03 和 V06 是分组，使用时选定具体子项。候选具备独立职责、封闭输入、可核验输出和已确认的业务口径后，方可孵化为方法；调用时按有权使用的目录快照解析到 `method_id`、版本和摘要。

- **工具候选**用 ToolProcedure 描述固定职责、停止条件与实现。历史 D 类表示确定性处理，表中的脚本或平台函数是拟用载体，也可评估获准的受管 MCP。历史 N 类表示在限定材料内作有界判断，可拟为指令工具，必须验证模型轮次、隔离、输出与费用。
- **组合候选**用 C01–C15 记录目的、依赖与待定项。步骤结构、候选与连线可映射为编辑草图；五要素中的承诺、权限、校验、审批仍由通用模板的固定内容、变量和约束表达。变量闭合后才形成具体工作稿，调用资格来自测试冻结。
- **现阶段能验证的范围**是私有宿主测试、唯一串行计划和零内部模型轮次的 MCP 叶子。单个指令、脚本、平台工具须先通过对应载体的执行验证，再进入正式编排。平台计算是否经托管 MCP 提供仍待定。

### 3.2 勾稽与质量核验（`Q01–Q06`，源自 M02）

| `CatalogKey` / 原号 | 拟用载体 | 必需输入 | 输出与规则 |
| :--- | :--- | :--- | :--- |
| `fin_check_balance_sheet` (`Q01`) | `skill_script` | 同时点资产 `A`、负债 `L`、权益 `E`、精度 | `A - L - E` 与平衡状态；`abs(diff) > 1元` 判不平；禁用负债权益合计反推缺失 `E` |
| `fin_check_profit_attr` (`Q02`) | `skill_script` | 同期间净利润 `NP`、归母 `P`、少数 `M`、精度 | `NP - P - M` 与状态；三项均需独立事实，不以未分配利润桥替换 |
| `fin_check_cash_roll` (`Q03`) | `skill_script` | 同口径期初现金、净变动、期末现金 | `END - BEGIN - CHANGE` 与状态；现金及等价物范围须一致 |
| `fin_check_opening_cont` (`Q04`) | `skill_script` | 同余额日上期期末与本期期初存量科目 | 有符号差额与状态；拒收累计流量 |
| `fin_check_retained_earn` (`Q05`) | `skill_script` | 期初期末未分配利润、归母净利、提取分配调整 | 滚动桥与未解释差额；容差单独定型（不默认 1 元） |
| `fin_compare_restatement` (`Q06`) | `skill_instruction` | 原版/重述版事实、重述披露说明 | 差异表与原因证据；数值由程序比对，无披露不自称重述 |

Q01–Q04 的原作者规则是绝对差额严格大于 1 元才判不平，等于 1 元不触发，披露精度不足则交未核验。首版是否采用由作者逐项确认；Q05 的容差独立定型。

> **编排边界**：Q 类返回“不平”属于**正常业务发现**，不应触发工具重跑；是否阻断下游预测或标注提示由上层 `Orchestration` 规则决定。

## 四、C01—C15 组合与模板候选

每行是创作提纲。加号或并列项表示分别调用，各步一次；A06、O03、V06 等分组须展开到具体条目。独立分支首期按稳定拓扑串行执行。作者可从候选形成草图，人工选择和 AI 建议均经同一展开检查。工具选型、业务规则与允许变化分别记录，金融口径、阈值、外部数据源、测试期望答案逐项采用。
