# M09 · 前五大客户与供应商集中度透视

由原 20 法中的 M09 提炼。委托人给出同一报告的客户销售明细、供应商采购明细和各自总额，专家交付两侧前五占比、明确披露的关联交易金额及其占各自全年总额的比例、有双侧出处的重叠主体和未识别行。按作者本次决定，风险评级显示“待定”。

## 从原法到两个工具

原作者定义在 KnowLab 的 `app/tests/financial_author_method_fixtures.py`，方法键为 `customer_supplier_concentration_scan`。原稿允许匿名数据用于比例统计，关联身份依披露认定。[历史提炼清单 O05](../财务方法工具积木与模板提炼.md) · [提炼操作样板](../工具积木提取案例.md)

2026-11-27 只读核对了共享 KnowLab 中 sig-am 的自有冻结方法名称，包括勾稽核验、历史财报指标、单季流量、预测和成稿。未发现承担这两项职责的自有方法。新版实际选择器中的安装项仍需在作者会话核对。

| 工具 | 输入与固定职责 | 业务边界 |
| --- | --- | --- |
| 前 N 大交易对手集中度核算 | 用一张有排名和出处的表算一次。客户除以销售总额，供应商除以采购总额。记录被选行、分子、分母和精确分数 | 已披露不足 N 名时只报已披露小计占比。匿名行可参与金额计算。仅汇总有披露依据的关联行，未标明的行单列；全部未知时关联占比留空 |
| 前五大客户与供应商交叉复核 | 接收客户和供应商两份核算回执，核对主体、报告、期间、范围、单位和前五口径。输出两侧原回执、可确认的重叠主体及双侧证据 | 只有双方都给出同一规范主体键及其出处才匹配。匿名行保留原表定位；部分身份未知时，空匹配不能解释为没有重叠。评级待定 |

父稿选择两个工具，第一种各用一次，第三步接前两步输出。两端明细均须由调用人按披露表标注，整张表共用表头口径。核算实现没有联网取数和自动识别法律主体的职责。关联占比限于本表所列、已明确关联的交易金额，不能外推全公司的关联交易规模。

## 合成委托与独立期望

| 验收项 | 输入 | 手算期望 |
| --- | --- | --- |
| 前五客户 | 20、12、8、6、4，年度销售额 200 | 50 ÷ 200 = 25% |
| 前五供应商 | 20、10、8、4、3，年度采购额 100 | 45 ÷ 100 = 45% |
| 披露关联 | 双侧第一名各有 20 元明确关联，剩下四行未标注 | 已确认占销售 10%、采购 20%，各保留四个待核出处 |
| 双侧身份 | 只有第一名的披露能指向同一主体“甲” | 交回 C1、S1 及相应身份注释；覆盖为部分，评级待定 |
| 缺件与拒收 | 客户只披露 20、12；另测错分母、重复证据、逆序排名、跨报告期间 | 缺件时交回 32 ÷ 200 = 16%，完整前五占比留空；错误输入停止 |

[本地合成委托交付](合成样表交付.json)保留实际脚本输出。分数以分子／分母表示。复验还覆盖零分母、按 N 截取、没有已披露关联状态、全员实名但没有交叉身份等情形。

## 复跑与正式接续

在本目录执行（`verify.py` 使用 Python 的 `jsonschema` 包）：

```sh
python3 verify.py
python3 suites.py "$(mktemp -d)"
agy_app=/home/zymun/worktrees/agy/knowlab-app/knowlab-backend/app
PYTHONPATH="$agy_app" PYTHONDONTWRITEBYTECODE=1 "$agy_app/.venv/bin/python" verify_drafts.py
```

第一条以独立脚本进程核对正常、缺件与拒收情形。第二条生成两份工具套件与一份根专家套件，共五个正式试跑用例，已通过 agy 契约校验并在本地核对断言。第三条通过 agy 的工作稿服务实际创建两份 S1 工具稿和一份专家稿、保存修订、核对来源记录并取得运行申请，以内存仓储和测试引用编译展开。该测试的身份及引用仅在进程内有效。

正式接续时，先在 sig-am 的实际可用目录核对是否有可复用的同契约实现。对实际缺口，从工具作者入口创建工作稿，再登记对应的 [集中度核算脚本](concentration.py) 或 [交叉复核脚本](overlap.py)。以目标环境登记回读的完整来源对象和最新修订运行 `python3 drafts.py concentration 来源.json 修订号`（另一工具用 `overlap`），保存生成的工作稿。分别批准真实试跑、核对断言、冻结自用。将两条真实引用按 `concentration`、`overlap` 写入同一个 JSON 对象，各含 `method_id`、`version`、`digest`；`python3 parent.py 引用.json` 生成父稿，再对父稿实际试跑、冻结、自用登记并用独立委托复验。
