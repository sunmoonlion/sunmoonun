# 从 Wind 采集公司年报与研报并导入 KnowBase

2026-11-28 构建备忘。目标是让财务专家或即时编排按任务向 Wind 取原文，并在指定知识库中引用它。当前已实测 Windows 桌面研报下载。公司年报下载、KnowBase 入库、索引检索和正式工具孵化均待实施。

## 给作者的能力声明草案

给定证券代码和目标知识库，根据委托选取指定年度的公司年报全文、符合条件的机构研报，或同时采集两类。逐份交回来源、版本、KnowBase 文档标识和检索结果。资料不足时说明实际取得的数量与原因。

| 输入 | 约定 |
| --- | --- |
| 公司、资料类型 | 用含交易所的证券代码确认公司。公告和机构研报各自保留资料类型。 |
| 年报条件 | 指定报告年度，按年度核对全文及修订情况。发布日期可能在次年。 |
| 研报条件 | 指定篇数，可限定机构或日期。默认从当前账号有权下载且符合条件的结果中按 Wind 最新发布排序。平台发布时间与报告署期分别记录。 |
| 执行环境、入库位置 | 使用获授权并已登录 Wind 的 Windows 电脑，以及委托方指定、具有写权限的 KnowBase 知识库。构建时核对资料可存储及可共享的范围。 |

## 已走通的桌面路径

1. 从 Windows 桌面的「Wind金融终端」快捷方式启动。终端首页顶部选「资讯」，在「研报平台」栏目选「公司研报」，再选左侧「公司研究」。
2. 输入代码，从下拉框选择「代码」项，核对筛选栏中的完整证券代码。保留「最新发布」排序，取消「含无权限研报」，在列表逐条勾选，核对「已选」数量。
3. 点列表右上方「下载」，在文件对话框保存 Wind 生成的 ZIP。解压后逐份检查 PDF 可读性、标的与数量，按内容摘要检查重复。开发时以控件标签和当前窗口状态定位；本机测试用的屏幕坐标不宜写入方法契约。

| 可复用验收物料（Windows 桌面目录） | 已核实的内容 |
| --- | --- |
| 浦发银行600000研报 | 600000.SH，10 份不同 PDF，来自国信证券、银河证券和华福证券。此次从已打开的研报平台开始。 |
| 同方股份600100研报 | 600100.SH，10 份不同 PDF，从桌面启动终端。2 份中航证券财报点评，8 份 China Knowledge 分期评级。同名评级在不同日期可各自成篇。 |

上述 20 份目前只在本地。Wind 能力目录没有给出券商研报 PDF 的批量下载步骤。此次研报路径来自终端实操。

## 接手后的实施与验收

1. **先用现成 PDF 验通入库。** 选定测试知识库，核对现行导入接口、身份、文档标识和索引状态。用一份现有研报导入，按代码和报告中特有的一句话检索，验证命中的文档、发布机构及原文位置。上传成功但尚未检出的文件单独标记为待索引。
2. **补测年报来源。** 在 Wind「公司公告」按代码、报告年度选年度报告全文，记录实际菜单路径、披露日期、修订标识和可取得的来源标识。核对封面与正文，排除摘要以及券商发布的“年报点评”。用年报中一个有出处的财务项目验证入库后的检索。
3. **定义逐份回执和重试。** 每份记录目标库、代码、类型、标题、发布方、日期、来源、文件摘要、入库文档标识和检索状态。相同目标库内重复导入相同文件应复用已有文档；同名不同期或修订版应可区分。部分成功时保留已完成项，只重试失败环节。用重复运行、结果不足和部分导入失败各验一次。
4. **完成正式孵化。** 按当时的 KnowLab 作者流程创建工具方法工作稿，核实可调用的桌面执行能力和 KnowBase 写入能力，绑定获准的实现来源。用独立样例试跑年报、研报及部分失败场景，保留下载、入库和检索回执，通过后冻结为自用版本，再验证专家或即时编排能从可用目录调用。作者流程可参考[工具积木提取案例](工具积木提取案例.md)。
