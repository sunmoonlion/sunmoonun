## 作者页面与测试物料

1. 用 sig-am 本人会话新建私有孵化申请。创意填“请为四行小计编制可核对的汇总表”，勾选“从‘可核对交付’固定模板起草”。在工作稿写入下表四项，点击“确认口径，编排做法”。刷新后应能在同一申请看见相同口径。测试草稿如有原步骤，核对旧稿、确认新做法后保存。整个操作只用一个作者入口。
2. 使用确有资格的指令或已冻结的工具。可用本人测试指令“读取四行名称=金额，保留原顺序、零行和两位小数，冲减为负，第五行输出 Total=合计，仅返回这五行”。应在本人私有验收申请登记相应指令来源并从可选目录采用，使用 sig-am 的用户配置 Kimi 与本人电脑，记录实耗。采用已有来源时核对其实际指令、版本与摘要。目录为空时先核对工作稿仍已保存，记录缺何种来源。需要补源时用获准的私有测试来源。
3. 在样例表单填 A 四行输入，预期输出填同四行加第五行 `Total=45.00`，指明该正例覆盖模板的交付承诺，保存并试跑。核对实际四行、合计、版本及费用回执后冻结私有版本。指令直跑有一个文字输入和一个文字输出。要验证专家组合，可将通过试跑并冻结的工具从本人目录选入“怎么做”。
4. 将冻结专家的精确版本选入另一份私有验收申请，使用 B，逐行核对期望 `Total=17.00`。记录被调用版本及摘要、两次运行号和逐行产物。拿同一验收稿做反例时使用新的修订或独立副本，把合计期望改为 99.99，确认试跑失败、该回执无法冻结。保留旧稿与既有 Q01–Q04 的撤回事实现状。
5. 从“选已有工具编排”起步，在“怎么做”选择 P1 串行、P2 分工汇合、P3 独立分析与复核、P4 按对象处理、P5 按条件分工。按该图允许的做法选择候选、核对连线、采用、保存、重开。核对缺隔离能力时 P3 的阻断和提示。环境可运行的分支分别记实际产物；缺能力时记具体能力与状态。现成的冻结工具、分支输入、采用动作和预期回执见[可复跑的联调程序](../../../../../scripts/local-integration/p1_author.py)。本地夹具编号随运行生成，现场使用当前账号的获权版本。
