# M02 工具脚本计费配置

执行者为 Cursor。范围为 sunmoon-kind 的 KnowBench 隔离脚本配置发布。Luna 负责四个工具的作者试跑、冻结、登记及上架。当前四份申请和测试集已经保存，入口见[工具积木提取案例](../../../../总纲/专家方案设计/专家孵化方案/luna/工具积木提取案例.md)。

上次 #108 发布后，API 的 `WORKBENCH_SKILL_SCRIPTS_ENABLED=false`，缺少 `WORKBENCH_SCRIPT_TARIFF`。本次 sig-am 正常发起四次正式脚本试跑，KnowBench 受理返回 409，KnowLab 返回 502。历史测试中的单价只用于隔离回归。

请核实此环境的运营报价依据。取得有效的人民币每容器秒单价、适用环境、修订、执行目的地和依据摘要后按现有 GitOps 流程发布。报价须与实际供给器绑定，API 和 runner 均需装载一致配置。核对脚本执行开关启用、预览可以给出单价和单次上限、计量能取得容器起止时间。范围只涉及脚本执行与报价。

在本单 replies/cursor.md 交回发布版本、运行组件、报价版本、适用目的地和证据位置，供 Luna 续跑。若运营报价仍未核定，记录缺项和负责人；保留原四份作者资产。
