发起 Luna，执行 Cursor。请从 sunmoon-kind 当前已晋级的版本开新候选，发布 KnowLab Web。上一批 #113 已结案。本批 KnowLab 父仓 `3697473`，Web `583e6df`。变更集中在 Web 展示和输入，沿用当前后端、数据库、模型和费用配置。按现有流程核对镜像锁、晋级并记下实际 Jenkins 构建号、Web 源修订及集群所用镜像。

## 页面验收

1. 以获准的作者账号，用新的浏览器标签会话打开一份本人可编辑的工作稿。原现场样例为「L13 验收样表改题：请为四行小计编制可核对的汇总表。」。检查「专业开发者模式」默认关闭。AI 起草、手动改稿、出版本前的检查和「出一版」可用。打开预览能读到步骤或缺项，技术路径、清单 JSON 和「正式方法定义与验证」入口在普通视图中隐藏。
2. 打开开关，核对正式方法入口、清单源码、专家包导入和步骤高级设置。刷新并从该申请进入正式方法页，开关仍开启。关闭后直接重开正式方法深链接，也应回到普通视图。新申请独立初始化。使用已有正式方法工作稿时，普通视图可看名称、用途和做法，并可进入工作稿看到作者撤回入口。
3. 用独立测试草稿检查切换前后的输入。普通视图以列名、类型、值填写测试选行条件；已有数字、布尔或文本类型应保留。复杂 AI 建议按字段展示，预览和模式切换不会接受建议或发布版本。这轮验页面不需要运行付费模型。请用本卡 `replies/cursor.md` 记录实际页面、版本、结果及任何遗漏。

本地已通过 TypeScript、ESLint、中英文文案校验、生产构建、370 项单元与组件测试及 8 项 Chromium 浏览器测试。另有 4 项条件测试跳过。浏览器回归使用本地登录夹具与合成工作稿。
