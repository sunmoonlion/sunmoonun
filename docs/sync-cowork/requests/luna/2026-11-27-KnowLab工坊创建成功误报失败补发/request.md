**原因与改动。** 已发布 Web 要求公开输入和返回为数组，后端按槽位名称返回映射。创建成功和重新打开经过同一个解析器，都会失败。修复按名称读出输入、交付和缺少来源的承诺；从草稿读取待确认字段，并读取 #128 词表返回的嵌套标签。保存后按服务端原编号跳转。

**本地复验。** 使用已保存原稿的服务响应重放，原版解析失败，修复版通过。用生产构建与本地配对登录环境跑 Chromium，在表单填“三表核验 / 专家方法 / 核对”，一次提交后跳转到响应中的原编号，看到输出槽位，刷新后仍可读取。浏览器演练在本地重放响应；现场只读查证。KnowLab Web 类型、多语言及生产构建通过，全量 Vitest 374 项通过、4 项跳过。

**草稿删除。** 作者从工坊列表按编号选择草稿，确认框显示名称和短编号。取消不会发送请求。确认后以完整方法编号及看到的修订发送 DELETE，只能删除本人草稿；修订变化返回 409 并刷新列表。重复删除同一份已删除草稿返回 204。删除父草稿后，子草稿保留并解除缺口关联。原工作稿行继续供已有冻结版本、试跑和出处记录引用。

**删除验证。** 生产构建在 Chromium 中验证两个同名草稿，仅删除确认的编号并刷新复查；浏览器使用本地配对服务和模拟列表。独立 PostgreSQL 16 通过真实 API 验证 CSRF、归属、过期修订、重复请求、旧链接、同名隔离、子稿和冻结出处。两候选前端类型及多语言通过，补发 Web 全量 Vitest 375 项通过、4 项跳过。Luna 开发线后端定向 15 项通过。补发后端同组 13 项通过、2 项失败；在无本次改动的 `7e67b587` 上独立重现相同两项失败，均为 `test_knowbot_workdraft_db.py` 用已退役的固定包父申请作可编辑样本，返回 `request_not_found`。本次删除接口测试在两条线上均通过。
