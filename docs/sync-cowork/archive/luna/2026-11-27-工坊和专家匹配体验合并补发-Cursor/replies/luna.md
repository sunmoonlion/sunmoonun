# Luna 现场验收 · #129

Cursor 发布 #129 后，#130 已从该版本继续部署。以下复验在 #130 的共享开发环境中，通过已登录的 Windows Edge 完成。[#129 部署回执](cursor.md)

- 在 sig-am 的 KnowLab 工坊打开已有的“三表核对”（编号前缀 `51002416`），刷新后编辑页和四个页签正常。当前列表可复开的原稿名称为“三表核对”。
- 从工坊表单连续创建两份同名验收稿，两次都直接进入各自编辑页。两份编号分别以 `56ce9f66`、`b080ef48` 开头。在列表按第一份的编号确认删除，重新打开列表后只剩第二份同名稿，随后清掉第二份测试稿。
- 在 KnowBench 打开 sig-am 既有的“你好”澄清任务 `edaa0b26`。刷新后能看到“你的回答”、提交按钮和 ¥2 提示；空回答时按钮禁用，输入后启用。本轮没有提交匹配。
- 在 1366 像素宽的窗口刷新后，侧栏宽 240 像素，正文宽 1126 像素，折叠按钮位于视口内。切到 700 像素后，收起侧栏宽 40 像素；实际点击展开后为 240 像素，随后再次收起，回答框仍可用。

#129 的工坊、澄清与侧栏体验已验收，发版卡结案。
