## 远程云端容器接续

当前远程助手在无法 SSH 登录的云端容器，本地只能更新 GitHub/Gitee，不能替它切换进程所在的工作目录。容器内的助手先保存并提交自己的修改，再针对原来的工位逐仓迁移：

```bash
git fetch origin --prune
# 先检查 HEAD 中是否仍有未推送/未合入 qwen 的提交：有则先保留并合入，不能重置。
git log --oneline origin/qwen..HEAD
git switch qwen
git merge --ff-only origin/qwen
```

若本地 qwen 尚不存在，用 `git switch --track -c qwen origin/qwen`。若旧本地 qwen 有独有提交，先保留为本地归档标签再审读差异，不用强制切换掩盖问题。应用父仓切换后运行 `git submodule update --init --recursive`，再将各子仓接回相应工位分支。其它工位将 qwen 替换为同名工位即可。

日常不要推回旧 `work/*-20261106`、`fix/*`、`release/*` 分支，也不要执行 `git push --all`。历史发布提交与标签保留；需要恢复历史时从归档标签建立明确用途的新临时分支。
